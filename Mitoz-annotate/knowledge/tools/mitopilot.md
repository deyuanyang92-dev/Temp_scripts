## What it does
- R package with a Nextflow back end and a Shiny app: assembles mitogenomes from genome-skimming reads, annotates them with MITOS2 (rRNA and protein-coding genes) plus tRNAscan-SE (tRNAs), optionally MitoFinder, ARWEN and ARAGORN, then curates and validates against clade rulesets (32 rulesets: fish, birds, mammals, polychaetes, ctenophores, scyphozoans, etc.).
- For rRNA it contains no search code of its own: rrnS/rrnL come from MITOS2 (and optionally MitoFinder as a gap filler); MitoPilot adds a second MITOS2 pass, a tRNA "punctuation" end-snapping step, length/overlap/count validation, and a manual rRNA editor with a nucleotide alignment view.

## Algorithm & key source locations
- MITOS2 call: `runmitos --input <fa> --outdir <dir> --code <n> --refseqver <ref_db> --refdir . [--linear] <mitos_opts> <extra> --noplots`; defaults `ref_db = "Chordata"` and options `--best --intron 0 --oril 0` (`--best` is prepended by `use_mitos_best = TRUE`) (MitoPilot/R/annotate_mitos2.R:199-207) (MitoPilot/R/annotate_mitos2.R:221-240) (MitoPilot/R/annotate.R:53-56) (MitoPilot/R/annotate.R:66) (MitoPilot/R/annotate.R:251-255)
- MITOS2 reference directory must contain `auxinfo.json` and `ncRNA/`; the bundled curation tarballs Metazoa_RefSeq231/235 have neither, so only `Metazoa_RefSeq89` or `Chordata` can drive annotation; MITOS2 is always run with `--refdir .` (MitoPilot/R/annotate_mitos2.R:13-37)
- The rRNA covariance models are stock MITOS2 models: `Chordata/ncRNA/rrnS.cm` and `Metazoa/ncRNA/rrnS.cm` (also rrnL) are byte-identical (md5 prefix 676dfbb8 for rrnS, 3e50135b for rrnL) to our `refseq89m` files: CLEN 894 / 1537, NSEQ 7991 / 7902, built 2018-08-27 [our run 2026-10-21] (MitoPilot/ref_dbs/Mitos2/Chordata/ncRNA/rrnS.cm:5) (MitoPilot/ref_dbs/Mitos2/Chordata/ncRNA/rrnS.cm:22) (refseq89m/ncRNA/rrnS.cm:5) (refseq89m/ncRNA/rrnS.cm:22)
- MITOS2 output parsing: gene symbol = leading alphanumerics of the last token of the FASTA header, so a split MITOS2 hit such as `rrnS_0-a` / `rrnS_0-b` becomes plain `rrnS` in both rows; type "rRNA" if the symbol starts with `rrnL`/`rrnS`; product "16S/12S ribosomal RNA"; coordinates pos1/pos2 from the header, length is the arc around the origin if pos1 > pos2 (MitoPilot/R/annotate_mitos2.R:53) (MitoPilot/R/annotate_mitos2.R:67) (MitoPilot/R/annotate_mitos2.R:78-79) (MitoPilot/R/annotate_mitos2.R:115-119)
- MITOS2 splits one gene into parts `-a`, `-b` when the second hit's E-value is within 10x of the first and its model range overlaps <= 20 % (see tools/mitos2.md) (Mitoz-annotate/knowledge/tools/mitos2.md:41)
- "Rescue" pass (default on, option `rescue_no_trna`): after the normal MITOS2 run, MITOS2 is run again into `<out>_noTRNA` with `--trna 0`; every PCG or rRNA whose gene name is absent from the first run is appended; tRNAs always come from the first run and tRNAscan-SE. Stated reason: MITOS2 discards rRNAs/PCGs whose locus overlaps a predicted tRNA, e.g. a scyphozoan `rrnS` wedged against `nad5` with a tRNA in its span (MitoPilot/R/annotate_mitos2.R:192-195) (MitoPilot/R/annotate_mitos2.R:254-271) (MitoPilot/NEWS.md:555-557) (https://github.com/NMNH-OceanDNA/MitoPilot/pull/96)
- Combination priority tRNAscan-SE > ARWEN > ARAGORN > MITOS2 applies to tRNAs only (a MITOS2 tRNA is dropped when > 10 % of its length overlaps a call from the other tools); rRNAs are never compared with other tools except MitoFinder (MitoPilot/R/annotate.R:274-313)
- MitoFinder (off by default, "lowest priority"): runs `mitofinder -a <fasta> -r <GenBank> -o <code> --ignore`; its rRNA rows are mapped to rrnS/rrnL and dropped when > 10 % of their length overlaps any existing annotation, so they only fill gaps; the repository ships two fish GenBank references only (MitoPilot/R/annotate.R:332-376) (MitoPilot/R/annotate_mitofinder.R:87-97) (MitoPilot/R/annotate_mitofinder.R:188-193) (MitoPilot/ref_dbs/MitoFinder/NC_002333_Danio_rerio.gb:1)
- Duplicate collapse: rows with the same contig, gene and pos1 are reduced to the longest; nothing merges rRNA pieces with different starts (MitoPilot/R/annotate.R:462-469)
- Punctuation model for rRNA (curation step, `Applied punctuation model`): for every rRNA, if the previous row in position order is a tRNA, pos1 is set to tRNA pos2 + 1; if the next row is a tRNA, pos2 is set to its pos1 - 1; each change is made only if the resulting length is <= the rule's `max_len` and is written to the Notes column. It both extends over gaps and trims overlaps; there is no change when the neighbour is a PCG or the control region, and the circular wrap-around neighbour is handled (MitoPilot/R/curate_mito_core.R:270-331) (MitoPilot/vignettes/Curation-and-Validation.Rmd:46-50)
- The only rRNA length constants are `rrnL max_len = 1850` and `rrnS max_len = 1000`, identical in all 32 clade parameter files and hard-coded in the generator rather than taken from each clade's survey table (MitoPilot/data-raw/generate_clade_params.R:131-132) (MitoPilot/R/params_ctenophore_mito.R:39-46) (MitoPilot/R/params_polychaeta_mito.R:40-47)
- Reference alignment never changes rRNA ends automatically: top BLASTN hits against `featureNuc/rrnS.fas` / `rrnL.fas` are stored in `refHits` for the viewer, but the end-fixing loop returns every non-PCG row unchanged (`if (cur$type != "PCG") return(cur)`) (MitoPilot/R/curate_mito_core.R:391-406) (MitoPilot/R/curate_mito_core.R:418-420)
- Strand: if all rRNAs of a contig are on the minus strand the whole contig is reverse-complemented (not for Diptera); an optional step reverse-complements a contig to match its best BLAST reference, written for medusozoan genomes with rRNAs on opposite strands (MitoPilot/R/curate_mito_core.R:175-190) (MitoPilot/NEWS.md:553)
- Validation (flags only): rRNA `count = 1` (else "possible duplicate", the usual sign of a split MITOS2 hit), `max_len`, `min_len` (NA by default for rRNA), overlap with another feature on the same strand above `max_overlap` (0.25 in the ctenophore set), rRNA start overlap > 0 or stop overlap > 1, and "tRNA within PCG or rRNA" when a tRNA lies entirely inside one (MitoPilot/R/validate_mito_core.R:104-129) (MitoPilot/R/validate_mito_core.R:176-226) (MitoPilot/R/validate_mito_core.R:228-245) (MitoPilot/R/validate_mito_core.R:257-262) (MitoPilot/R/params_ctenophore_mito.R:9-17)
- Manual rRNA tools in the Shiny app: a nucleotide-boundary editor with 5'/3' nudge buttons, partial 5'/3' flags carried into the `.tbl`, an alignment of the rRNA to the RefSeq 235 rRNA database plus the best remote GenBank hit, and a Merge button that joins MITOS2 pieces of a split PCG or rRNA (MitoPilot/NEWS.md:663-667) (MitoPilot/NEWS.md:1174) (MitoPilot/vignettes/Test-Project-Annotate.Rmd:282-284)
- Reference data for rRNA curation: `Metazoa_RefSeq235/featureNuc/rrnS.fas` and `rrnL.fas` hold 15,647 and 15,651 sequences (length min / median / max: rrnS 56 / 935 / 21,114; rrnL 16 / 1546 / 23,133; 373 rrnS > 1000 bp and 327 rrnL > 1850 bp) [our run 2026-10-21] (Metazoa_RefSeq235/featureNuc/rrnS.fas:1) (Metazoa_RefSeq235/featureNuc/rrnL.fas:1) (MitoPilot/data-raw/build_curation_db.R:8-9)
- Export naming: rRNA genes are written `rrn12` / `rrn16` at NCBI's request; internally rrnS / rrnL (MitoPilot/NEWS.md:710-713)

## Defaults that matter
- MITOS2: `--best --intron 0 --oril 0`, `ref_db` Chordata, genetic code 2, rescue on; tRNAscan-SE `-M vert -X 20` (MitoPilot/R/annotate.R:48-67)
- Punctuation cap: rrnS <= 1000 bp, rrnL <= 1850 bp; `hit_threshold` 60 and `max_overlap` 0.25 in the ctenophore set (MitoPilot/R/params_ctenophore_mito.R:9-10) (MitoPilot/R/params_ctenophore_mito.R:39-46)
- Default curation reference database is `Metazoa_RefSeq235` (the only bundled one with rRNA BLAST references), independent of the MITOS2 annotation database (MitoPilot/NEWS.md:624) (MitoPilot/vignettes/Curation-and-Validation.Rmd:190-194)
- `--best` leaves MITOS2's second round off: only conflict-free first-round hits are kept (see tools/mitos2.md); what this does to rRNA pieces was not tested by us (未确证) (Mitoz-annotate/knowledge/tools/mitos2.md:44)

## Known bugs / issues
- MITOS2 loses an rRNA that overlaps a tRNA call (scyphozoan `rrnS` between `nad5` and a tRNA); MitoPilot's fix is the extra `--trna 0` run, which adds a second MITOS2 run per sample (a checkbox disables it "to save runtime") (MitoPilot/NEWS.md:555-557)
- Fixed in 1.5.x: rRNA/PCG features that wrap the origin of circular contigs were mishandled in overlap helpers and in the editor (MitoPilot/NEWS.md:288-294)
- The 1000 / 1850 caps are the same for every clade, so an extension that would make a genuinely longer rRNA exceed them is silently not applied (the note is simply absent); 373 of 15,647 RefSeq rrnS and 327 of 15,651 rrnL exceed them (the largest are probably annotation artefacts, not checked) (MitoPilot/R/curate_mito_core.R:305) (MitoPilot/R/curate_mito_core.R:323) (Metazoa_RefSeq235/featureNuc/rrnS.fas:1)
- The punctuation step acts only when the adjacent row (after sorting by pos1) is a tRNA; an rRNA next to a PCG, the control region, or next to a missing tRNA is left as MITOS2 drew it (MitoPilot/R/curate_mito_core.R:297-325)
- Development is active (last push 2026-10-20) and the changelog lists several rRNA-related fixes, but there is no benchmark of rRNA accuracy in the repository (未确证 that none exists elsewhere) (https://api.github.com/repos/NMNH-OceanDNA/MitoPilot)

## Limitations by taxon
- Rulesets exist for 32 clades, mainly vertebrates, molluscs, echinoderms, cnidarians, sponges, ctenophores, annelids, arthropods; there is none for Chaetognatha, Placozoa, Acoela, Kinorhyncha, Nematoda or Tardigrada (file listing of `R/params_*_mito.R`), and since the rRNA rules are the same constants in all rulesets, a ruleset would not change rRNA handling anyway (MitoPilot/R/params_ctenophore_mito.R:1) (MitoPilot/data-raw/generate_clade_params.R:131-132)
- rRNA detection in divergent phyla is exactly as good as the MITOS2 `rrnS.cm` / `rrnL.cm` models (trained on RefSeq mitogenomes, NSEQ 7991 / 7902) plus the extra tRNA-free pass; no other detector is added (MitoPilot/ref_dbs/Mitos2/Chordata/ncRNA/rrnS.cm:22)
- The default MITOS2 annotation database is `Chordata`; for other phyla the user must select `Metazoa_RefSeq89` (the ncRNA models are the same files, the protein families differ) (MitoPilot/R/annotate.R:53) (MitoPilot/R/annotate_mitos2.R:30-32)
- Medusozoan genomes (linear, rRNAs on opposite strands, tRNA-poor) were the case that forced the rescue pass and the reference-based strand step; ctenophore and sponge rulesets exist but their rRNA behaviour is not described separately (MitoPilot/NEWS.md:544) (MitoPilot/NEWS.md:553-557)

## Relevance to our pipeline
- Closest published precedent to our rRNA problem: MitoPilot treats "MITOS2 misses or shortens an rRNA" with (i) a second MITOS2 run without tRNAs, (ii) tRNA-based end snapping with a length cap, (iii) validation flags, and (iv) a human editor. It has no automatic rescue for divergent phyla [inference]
- Idea 1 (rescue pass without competitors): MITOS2 rejects an rRNA hit that conflicts with an already accepted feature, and the first-round order is protein, tRNA, rRNA. For MitoM, take rRNA candidates straight from `cmsearch` (all hits at E <= 0.01, local mode) before any tRNA/PCG conflict resolution, then resolve conflicts ourselves; and drop (or mark low-confidence) a tRNA lying entirely inside an rRNA or PCG, using MitoPilot's validation rule instead of letting it displace the rRNA. Test on the genomes where MitoM lost rRNA [inference] (MitoPilot/R/validate_mito_core.R:228-245) (Mitoz-annotate/knowledge/tools/mitos2.md:43)
- Idea 2 (derive the end-snapping cap from data): replace the fixed 1000 / 1850 caps by per-phylum quantiles of RefSeq rRNA lengths (the RefSeq 235 rRNA sets are in the repository), with a lower cap for Nematoda / Tardigrada style short rRNAs and an upper bound for Cnidaria / Ctenophora; apply the extension only if the snapped length lies inside the quantile range, otherwise keep the CM ends and flag it [inference]
- Idea 3 (merge pieces automatically): MitoPilot only warns "possible duplicate" and leaves merging to a button. For MitoM, merge MITOS2/cmsearch pieces of one rRNA automatically when they are on the same strand, collinear in model coordinates (using the `mdl from/to` columns), separated by less than a small gap or by a gap containing no other gene, and the merged length is within the phylum range; keep a note listing the pieces [inference]
- Idea 4 (partial rRNA instead of missing): MitoPilot lets the user mark an rRNA partial at either end, and the `.tbl` export carries the markers; for a divergent phylum where only part of the rRNA matches a model, emit a partial rRNA (5'/3' flag) instead of no rRNA, and let the benchmark score it separately [inference] (MitoPilot/NEWS.md:663-667)
- Idea 5 (reference-nucleotide fallback): when no CM hit exists, BLASTN or `cmalign` of the intergenic region between two anchors (flanking tRNAs/PCGs) against rRNA sequences of the closest available phylum (MitoPilot ships 15.6 k RefSeq 235 rrnS/rrnL sequences) could locate the rRNA, as MitoFinder does; MitoPilot builds the database but uses it only for display [inference] (MitoPilot/R/curate_mito_core.R:391-406)
- Our existing R1 (trim/fill to neighbouring genes) is the same idea as the punctuation model; the difference to adopt is the explicit length cap and the note text, and the difference to avoid is limiting snapping to tRNA neighbours only [inference]
