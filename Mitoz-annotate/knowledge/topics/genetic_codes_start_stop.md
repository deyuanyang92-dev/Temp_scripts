# Metazoan mitochondrial genetic codes, start codons, stop codons

Scope: NCBI translation tables used by metazoan mtDNA, how start/stop codons differ per table, how incomplete (T/TA) stops are written for NCBI, and which mistakes show up when a benchmark annotation is compared with RefSeq. Everything below was read on 2026-10-20 from the cited page or record; "decoded" means the 64-character ncbieaa/sncbieaa strings of gc.prt were decoded with a script (codon order TCAG, first base slowest).

## Where the tables live
- The NCBI "Genetic Codes" page (last update printed on it: Sep. 23, 2024) uses T instead of U; the initiator codon is by default translated as Met; possible initiators are the M entries of the "Starts" row (https://www.ncbi.nlm.nih.gov/Taxonomy/Utils/wprintgc.cgi)
- The machine-readable file gc.prt holds, per table, a 64-letter amino-acid string (ncbieaa, `*` = stop) and a 64-letter start string (sncbieaa, `M` = allowed start); decoding gives the same starts and stops as the web page for tables 2, 3, 4, 5, 9, 13, 14, 16, 21, 22, 23, 24, 33 (https://ftp.ncbi.nih.gov/entrez/misc/data/gc.prt)
- The mitochondrial code of a taxon is stored on the taxonomy node (fields MitoGeneticCode: MGCId, MGCName), e.g. Cnidaria taxid 6073 returns MGCId 4 (https://eutils.ncbi.nlm.nih.gov/entrez/eutils/efetch.fcgi?db=taxonomy&id=6073&retmode=xml)
- In a GenBank/RefSeq CDS the code appears as `/transl_table=<integer>` (1 = universal); genetic-code exceptions outside the tables go in `/transl_except` (https://www.insdc.org/submitting-standards/feature-table/)

## Mitochondrial tables relevant to metazoa (decoded from gc.prt)
- Table 2 Vertebrate Mitochondrial: TGA = Trp, ATA = Met, AGA and AGG = stop; stops TAA TAG AGA AGG; starts ATT ATC ATA ATG GTG; range Vertebrata (https://ftp.ncbi.nih.gov/entrez/misc/data/gc.prt) (https://www.ncbi.nlm.nih.gov/Taxonomy/Utils/wprintgc.cgi)
- Table 2 alternative initiation codons listed by NCBI: Bos AUA; Homo AUA, AUU; Mus AUA, AUU, AUC; Coturnix and Gallus also GUG (https://www.ncbi.nlm.nih.gov/Taxonomy/Utils/wprintgc.cgi)
- Table 4 Mold, Protozoan, Coelenterate Mitochondrial (also Mycoplasma/Spiroplasma): only change is TGA = Trp; stops TAA TAG; starts TTA TTG CTG ATT ATC ATA ATG GTG; metazoan range "Coelenterata (Ctenophora and Cnidaria)" (https://ftp.ncbi.nih.gov/entrez/misc/data/gc.prt) (https://www.ncbi.nlm.nih.gov/Taxonomy/Utils/wprintgc.cgi)
- Table 5 Invertebrate Mitochondrial: TGA = Trp, ATA = Met, AGA and AGG = Ser; stops TAA TAG; starts TTG ATT ATC ATA ATG GTG; range Nematoda (Ascaris, Caenorhabditis), Bivalvia, Polyplacophora, Artemia, Insecta (Drosophila, Locusta, Apis) (https://ftp.ncbi.nih.gov/entrez/misc/data/gc.prt) (https://www.ncbi.nlm.nih.gov/Taxonomy/Utils/wprintgc.cgi)
- Table 5 notes on the NCBI page: AGG is absent in Drosophila; several arthropods translate AGG as Lys (Abascal et al.); AUC is a start in Apis, GUG in Polyplacophora, UUG in Ascaris and Caenorhabditis; AUU is not used as initiator in Mytilus (https://www.ncbi.nlm.nih.gov/Taxonomy/Utils/wprintgc.cgi) (doi:10.1371/journal.pbio.0040127)
- Table 5 note: Drosophila COX1 has no in-frame AUG-like start; NCBI quotes Fox (1987) that initiation seems to need the AUAA quadruplet, or that the mRNA is edited (https://www.ncbi.nlm.nih.gov/Taxonomy/Utils/wprintgc.cgi)
- Table 9 Echinoderm and Flatworm Mitochondrial: TGA = Trp, AAA = Asn, AGA and AGG = Ser, ATA stays Ile; stops TAA TAG; starts only ATG and GTG; range Asterozoa, Echinozoa, Rhabditophora (https://ftp.ncbi.nih.gov/entrez/misc/data/gc.prt) (https://www.ncbi.nlm.nih.gov/Taxonomy/Utils/wprintgc.cgi)
- Table 13 Ascidian Mitochondrial: TGA = Trp, ATA = Met, AGA and AGG = Gly; stops TAA TAG; starts TTG ATA ATG GTG; NCBI adds that ATT is the CytB start in Halocynthia roretzi and that this species has an extra tRNA gene with anticodon U*CU believed to read AGA/AGG as Gly (https://ftp.ncbi.nih.gov/entrez/misc/data/gc.prt) (https://www.ncbi.nlm.nih.gov/Taxonomy/Utils/wprintgc.cgi)
- Table 14 Alternative Flatworm Mitochondrial: TAA = Tyr, TGA = Trp, AAA = Asn, AGA and AGG = Ser; the only stop is TAG; the only start is ATG; NCBI range "Platyhelminthes and Nematoda" (https://ftp.ncbi.nih.gov/entrez/misc/data/gc.prt) (https://www.ncbi.nlm.nih.gov/Taxonomy/Utils/wprintgc.cgi)
- Table 14 comment on the NCBI page: it differs from table 9 only by TAA = Tyr; one study found no evidence for TAA = Tyr in flatworms; there are very few records translated with 14 and retranslating them with 9 can cause premature terminations; TAA = Tyr was found in the nematodes Radopholus similis and R. arabocoffeae (https://www.ncbi.nlm.nih.gov/Taxonomy/Utils/wprintgc.cgi)
- Table 21 Trematode Mitochondrial: TGA = Trp, ATA = Met, AAA = Asn, AGA and AGG = Ser; stops TAA TAG; starts ATG GTG; range "Trematoda" (https://ftp.ncbi.nih.gov/entrez/misc/data/gc.prt) (https://www.ncbi.nlm.nih.gov/Taxonomy/Utils/wprintgc.cgi)
- Table 24 Rhabdopleuridae Mitochondrial (Rhabdopleura compacta, Pterobranchia): TGA = Trp, AGA = Ser, AGG = Lys, ATA stays Ile; stops TAA TAG; starts TTG CTG ATG GTG (the page text names ATG and GTG for R. compacta) (https://ftp.ncbi.nih.gov/entrez/misc/data/gc.prt) (https://www.ncbi.nlm.nih.gov/Taxonomy/Utils/wprintgc.cgi)
- Table 33 Cephalodiscidae Mitochondrial: like 24 but TAA = Tyr; the only stop is TAG; starts TTG CTG ATG GTG; NCBI cites Li et al. 2019 (https://ftp.ncbi.nih.gov/entrez/misc/data/gc.prt) (https://www.ncbi.nlm.nih.gov/Taxonomy/Utils/wprintgc.cgi) (doi:10.1093/gbe/evy254)
- Tables 3, 16, 22, 23 are mitochondrial codes of yeasts, green algae and a labyrinthulid, not metazoa (3: CUN = Thr; 16: TAG = Leu; 22: TCA = stop, TAG = Leu; 23: TTA = stop) (https://ftp.ncbi.nih.gov/entrez/misc/data/gc.prt)
- Pairwise differences that matter when a table is mis-assigned: 5 vs 9 differ at AAA (Lys vs Asn) and ATA (Met vs Ile); 9 vs 14 differ only at TAA; 24 vs 33 differ only at TAA; 5 vs 13 differ at AGA/AGG (Ser vs Gly); 2 differs from all others by AGA/AGG = stop (https://ftp.ncbi.nih.gov/entrez/misc/data/gc.prt)

## Start codons: tables versus what RefSeq actually contains
- The tables do not cover non-canonical starts and gene-specific usage: an analysis of RefSeq 63 found ATG the most frequent start, the whole ATN box frequently annotated in code 5 and 13 genomes, and TTG annotated in table 9 genomes although table 9 lists only ATG and GTG (doi:10.1093/nar/gkz833)
- In RefSeq annotations cox1 is a hotspot of non-canonical starts in invertebrates (9.8 % of cox1 starts, 312 of 338 within Arthropoda); in table 5 genomes TTA, ACG, CAA, CCG, CGA, TCG are annotated; in table 9 genomes TTT, TAT, GGA, GAT, CTG (doi:10.1093/nar/gkz833)
- Starts defined in the tables but practically never annotated: TTA and CTG in table 4, CTG ATT GTG in table 24 (the single table-24 genome) (doi:10.1093/nar/gkz833)
- MITOS (old method) searched only +-6 amino acids around the first prediction with strict NCBI tables and differed from RefSeq in more than 40 % of PCGs; the probabilistic MITOS2 method agreed with RefSeq for 77.5 % of starts and 75.8 % of stops on genomes new in RefSeq 89 (doi:10.1093/nar/gkz833)
- Seen in the fetched records (table 2): human NC_012920.1 ND1 ATA, ND2 ATT, ND3 ATA, ND5 ATA, other CDS ATG (computed from the record sequence) (https://eutils.ncbi.nlm.nih.gov/entrez/eutils/efetch.fcgi?db=nuccore&id=NC_012920.1&rettype=gb&retmode=text)
- Seen in the fetched records (table 5): C. elegans NC_001328.1 ND2, CYTB, ND4 start TTG; ND4L, ATP6, COX1, COX2, ND3, ND5 start ATT; ND6, ND1, COX3 start ATA (computed from the record sequence) (https://eutils.ncbi.nlm.nih.gov/entrez/eutils/efetch.fcgi?db=nuccore&id=NC_001328.1&rettype=gb&retmode=text)
- Seen in the fetched records (table 4): Montipora cactus NC_006902.1 ND5, ND1, ND4, COX3, ND4L, ND3 start GTG, ND6 starts ATA, the rest ATG; all 13 CDS end in complete TAA or TAG and none has transl_except (computed from the record sequence) (https://eutils.ncbi.nlm.nih.gov/entrez/eutils/efetch.fcgi?db=nuccore&id=NC_006902.1&rettype=gb&retmode=text)
- Drosophila NC_024511.2: COX1 is partial `<1474..3009` with note "start codon not determined" and begins TCG; ND1 begins ATA in RefSeq; a re-annotation by RNA-seq argues ND1 starts with TTG (adds 9 nt TTGTTTTAT upstream), COX1 start CCG in D. simulans, ATC in ATP8/6 and GTG in ND5 (https://eutils.ncbi.nlm.nih.gov/entrez/eutils/efetch.fcgi?db=nuccore&id=NC_024511.2&rettype=gb&retmode=text) (doi:10.1101/2021.06.05.447193)
- The same preprint notes that CDS ends cannot be derived from ORF analysis alone and that COII ORFs start at the 5th or 6th mRNA position because a short leader (AATAA in D. melanogaster) precedes ATG (doi:10.1101/2021.06.05.447193)
- Alternative starts are translated as Met in the GenBank translation (users read this as mistranslation, e.g. COX1 starting GTG in tilapia) (knowledge/tools/mitoz.md:58)
- table2asn test with code 5: ATG, ATT and GTG starts pass, CTG fails with SEQ_FEAT.StartCodon (knowledge/tools/table2asn.md:31)

## Stop codons: complete, incomplete T/TA, and AGA/AGG in vertebrates
- tRNA punctuation model: the 3' end of each human H-strand mRNA lies directly next to a tRNA gene (or another mRNA), the H strand is transcribed as one polycistronic RNA and cut before and after tRNA sequences (doi:10.1038/290470a0)
- NCBI page: mitochondrial genes of some vertebrates (including humans) have incomplete stop codons ending in U or UA that become UAA upon polyadenylation (cites Hou 2006, Oh 2007, Ki 2010, Temperley 2010) (https://www.ncbi.nlm.nih.gov/Taxonomy/Utils/wprintgc.cgi)
- NCBI page: AGA and AGG are not recognised as terminators in human mitochondria; a -1 mitoribosome frameshift happens at the AGA/AGG predicted to end COX1 and ND6, so both ORFs end in standard UAG (https://www.ncbi.nlm.nih.gov/Taxonomy/Utils/wprintgc.cgi) (doi:10.1126/science.1180674)
- In RefSeq human NC_012920.1 the COX1 CDS 5904..7445 ends in AGA and ND6 complement(14149..14673) ends in AGG, with no transl_except, so a table-2 translation stops there (computed from the record sequence) (https://eutils.ncbi.nlm.nih.gov/entrez/eutils/efetch.fcgi?db=nuccore&id=NC_012920.1&rettype=gb&retmode=text)
- In RefSeq AGA/AGG ends are annotated only for a subset of vertebrate PCGs and less often than TAR; internal AGR occurs rarely inside nad3 and nad4l (doi:10.1093/nar/gkz833)
- Incomplete stops T and TA are annotated throughout Metazoa but not consistently; T is annotated more often than TA; RefSeq prefers incomplete stops over small overlaps, yet RefSeq 63 has 2085 annotations of genes overlapping more than 10 bp (doi:10.1093/nar/gkz833)
- Suggestion of the same authors: gene features should not contain the polyadenylated positions, CDS features should (doi:10.1093/nar/gkz833)
- Human NC_012920.1: six of 13 CDS carry `/transl_except=(pos:...,aa:TERM)`: ND1 pos:4261..4262 (TA), ND2 pos:5511, COX3 pos:9990, ND3 pos:10404, ND4 pos:12137, CYTB pos:15887 (single T); note "TAA stop codon is completed by the addition of 3' A residues to the mRNA" (https://eutils.ncbi.nlm.nih.gov/entrez/eutils/efetch.fcgi?db=nuccore&id=NC_012920.1&rettype=gb&retmode=text)
- Drosophila NC_024511.2: four of 13 CDS carry transl_except: ND2 pos:1263, COX2 pos:3767, ND5 pos:complement(6409), ND4 pos:complement(8207), all with the same note; the others end in complete TAA or TAG (https://eutils.ncbi.nlm.nih.gov/entrez/eutils/efetch.fcgi?db=nuccore&id=NC_024511.2&rettype=gb&retmode=text)
- C. elegans NC_001328.1 and Metridium NC_000933.1 have no transl_except at all; every CDS ends in a complete TAA or TAG (computed from the record sequences) (https://eutils.ncbi.nlm.nih.gov/entrez/eutils/efetch.fcgi?db=nuccore&id=NC_001328.1&rettype=gb&retmode=text) (https://eutils.ncbi.nlm.nih.gov/entrez/eutils/efetch.fcgi?db=nuccore&id=NC_000933.1&rettype=gb&retmode=text)
- Overlap instead of incomplete stop: human ATP8 8366..8572 and ATP6 8527..9207 overlap by 46 nt, ND4L 10470..10766 and ND4 10760..12137 by 7 nt; Donath et al. quote the 46 nt ATP8/ATP6 overlap as an example of overlaps being under-annotated (https://eutils.ncbi.nlm.nih.gov/entrez/eutils/efetch.fcgi?db=nuccore&id=NC_012920.1&rettype=gb&retmode=text) (doi:10.1093/nar/gkz833)
- Stops that NCBI tables do not list but RefSeq annotates at low frequency: TTT, GCA, AAG in table 9; TTA, CAC, CCA for nad5 in invertebrates (the paper's text says "code table 4" there) (doi:10.1093/nar/gkz833)
- Number of CDS with transl_except (incomplete stop written for NCBI) in fetched RefSeq records: human NC_012920.1 6, chimpanzee NC_001643.1 4, mouse NC_005089.1 3, Platynereis NC_000931.1 9, Drosophila NC_024511.2 4, Mytilus NC_006161.1 2, Apis NC_001566.1 1, sea urchin NC_001453.1 1, C. elegans/Metridium/Montipora 0; so T/TA handling differs even between close relatives and a benchmark must compare stop codons by sequence, not by presence of transl_except (https://eutils.ncbi.nlm.nih.gov/entrez/eutils/efetch.fcgi?db=nuccore&id=NC_001643.1&rettype=gb&retmode=text) (https://eutils.ncbi.nlm.nih.gov/entrez/eutils/efetch.fcgi?db=nuccore&id=NC_000931.1&rettype=gb&retmode=text) (https://eutils.ncbi.nlm.nih.gov/entrez/eutils/efetch.fcgi?db=nuccore&id=NC_005089.1&rettype=gb&retmode=text)

## How NCBI wants stops, partials and codes written
- Incomplete stop: use `/transl_except=(pos:<base>,aa:TERM)` for a one-base partial stop, `(pos:<b1>..<b2>,aa:TERM)` for two bases, with note "stop codon completed by the addition of 3' A residues to the mRNA"; `/exception` must not be used where transl_except is adequate (https://www.insdc.org/submitting-standards/feature-table/)
- Partial ends are written with `<` and `>` in the location; the `/partial` qualifier is not to be used for new entries since 2001-12-15 (https://www.insdc.org/submitting-standards/feature-table/)
- `/codon_start` must be 1 for CDS with complete amino-termini; SP-GenBank assumes 1 when omitted (https://www.insdc.org/submitting-standards/feature-table/) (https://www.ncbi.nlm.nih.gov/genbank/organelle_submit/)
- SP-GenBank translates CDS with the appropriate genetic code and reports internal stops; NCBI metazoan checklist: "These coding regions use the mitochondrial TAA stop" (https://www.ncbi.nlm.nih.gov/genbank/organelle_submit/)
- table2asn: genetic code is set in the FASTA defline as `[gcode=4]`, topology `[topology=circular]`, location `[location=mitochondrion]` (https://www.ncbi.nlm.nih.gov/genbank/table2asn/)
- Without a record-level code table2asn gives SEQ_FEAT.GenCodeMismatch ("Genetic code conflict between CDS (code 5) and BioSource (code 0)") but still translates with the CDS transl_table (knowledge/tools/table2asn.md:20)
- SEQ_FEAT.NoStop = CDS not partial at 3' and not ending in a stop; fixes: extend to the stop, mark 3' partial, or /pseudo (https://www.ncbi.nlm.nih.gov/genbank/genome_validation/)
- A T/TA-ended CDS with only the note (no transl_except) still gets NoStop; adding transl_except on the last base(s), with `complement(...)` on the minus strand, removes it; a wrongly placed transl_except gives CDSrange and TransLen errors (knowledge/tools/table2asn.md:27-29)
- SEQ_FEAT.StartCodon: CDS not partial at 5' and not beginning with a start codon of the table in use; fixes: correct genetic code, extend to the start, mark 5' partial, or /pseudo (https://www.ncbi.nlm.nih.gov/genbank/genome_validation/)

## Frequent errors that look like benchmark discrepancies
- Wrong table gives internal stops: NCBI names the genetic code first among the causes of SEQ_FEAT.InternalStop, then CDS location and reading frame (https://www.ncbi.nlm.nih.gov/genbank/genome_validation/)
- Internal TAG codons: 83 in four of six Clathrina (Porifera: Calcarea) genomes NC_021112 to NC_021115 and in one Cubaia aphrodite gene, all with table 4 where TAG is a stop (doi:10.1093/nar/gkz833)
- Internal TAA codons: 231 in seven table-5 genomes (one mollusc, four hexapods, one crustacean, one nematode) (doi:10.1093/nar/gkz833)
- Table 14 assigned without support: TAA is the most frequent codon in Radopholus similis (157 occurrences, table 14 justified); two platyhelminth records carry 14 but TAA is internal only five times (KT008005) or never (KX943545) (doi:10.1093/nar/gkz833)
- Approximate gene positions in GenBank can hide the problem: nad2 of Hydractinia polyclina (LN901196) is `<4787..>5822` and contains 60 internal TAA (doi:10.1093/nar/gkz833)
- Donath et al. state that stops inside PCGs are most likely annotation or sequencing errors, a false code assignment or RNA editing rather than real code variation (doi:10.1093/nar/gkz833)
- MitoZ GeneWise step always uses a fixed invertebrate codon table (TAA/TAG = X, TGA = W, ATA = M, AGA/AGG = S) whatever --genetic_code says; effect on code 2 and 9 boundaries is 未确证 (knowledge/tools/mitoz.md:24)
- MitoZ stop revision looks 1 to 9 codons downstream for a complete stop before testing for T/TA, so a CDS that truly ends in T/TA can be extended up to 27 nt into the next gene (knowledge/tools/mitoz.md:27) (knowledge/tools/mitoz.md:54)
- Genes crossing the sequence origin are annotated only in part by MitoZ (missing start or stop) (knowledge/tools/mitoz.md:57)
- RefSeq itself is not a clean gold standard: a manual analysis found more than a dozen errors (missing tRNAs, inaccurate positions, wrong strand, incorrect anticodons) in 7 of 16 echinoderm mitogenomes (doi:10.1093/nar/gkr1131)
- RefSeq NC_024511.2 (Drosophila) is PROVISIONAL and its ND1 start, five tRNA ends and control region boundary were questioned by an RNA-seq re-annotation (https://eutils.ncbi.nlm.nih.gov/entrez/eutils/efetch.fcgi?db=nuccore&id=NC_024511.2&rettype=gb&retmode=text) (doi:10.1101/2021.06.05.447193)
