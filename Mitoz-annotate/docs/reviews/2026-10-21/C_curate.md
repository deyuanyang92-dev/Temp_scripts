## Checked and found correct (no finding)
- ncbi_validate.feature_lines part order: Biopython 1.86 parses `complement(join(10..20,30..40))` as parts [30..40, 10..20] (transcript order) and writes them back reversed, so "no reversal for strand -1" is right for parsed records and for rescue/curate/trna-built locations (all transcript order). Only the `<` / `>` columns are wrong (finding 1).
- mito_curate P5/P6 end choice: 5'-partial = BeforePosition(start) on +, AfterPosition(end) on -; 3'-partial = AfterPosition(end) on +, BeforePosition(start) on -; both survive P5 then P6 on the same CDS; gene feature is synced to the same location.
- O1 join coordinates (0-based half-open, + : [(a-1,L),(0,k)], - : [(0,L+1-a),(L-k,L)] in transcript order): extraction ends in a stop codon on both strands (script run); MAX_ORIGIN_EXT bounds k <= 300.
- transl_except position for T/TA stops on - strand (`complement(gs..gs+tail-1)`) matches the 3' end (low coordinate).
- mito_rescue origin-spanning features: `[b, a]` for - and `[a, b]` for + strand give correct `extract()` and a correct GenBank round trip (script run); translation equals `extract().translate()`.
- mito_intron exon order: all exons are kept genome-ascending in Report/Model; `locs[::-1]` for strand -1 in apply_model gives transcript order; stop_qualifiers uses `parts[-1]` = 3' end on both strands.
- runmitos_fast: cmout naming, dry-pass cleanup, pre-existing files, `remove_empty` patch and module-attribute patching all match mitos 2.x source (mitfi/__init__.py, scripts/runmitos.py).
- mitoz_fast failure fallback: RuntimeError from mito_trna.mitos2 (missing result.bed) goes to the original MiTFi step; subprocess timeouts and OSError are turned into the same RuntimeError path.
