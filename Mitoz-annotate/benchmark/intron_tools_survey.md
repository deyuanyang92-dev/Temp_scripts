# Survey: tools/methods for organellar (esp. mitochondrial) intron prediction
Started 2026-10-10. Items marked "unverified" were not confirmed from a primary source in this session.


## 1. MFannot + RNAweasel (Lang lab, Univ. Montreal)
- Intron types: group I (subgroups IA1, IA3, IB, IB3, IC1, IC2, ID by ERPIN) and group II (domain V based; plus models for domain V of mito/cp). Also intron-encoded ORFs (LAGLIDADG/GIY-YIG/maturase/RT) via BLAST vs an "intronic_orfs.pep" library (mfannot script l.250-258; Lang 2023 step 2).
- Method: (a) protein-coding exons: Exonerate protein2genome (command in script l.2502: `--minintron 142 --maxintron N --intronpenalty -35 --splice3/--splice5 Splice/neutral.pssm`, i.e. a flat 25/25/25/25 PSSM = deliberately neutral) + HMMER hmmsearch; (b) intron identification: RNAweasel (ERPIN sequence+secondary-structure profiles; "more recently Infernal"); (c) LVL_INTRON option 1/2 (level of intron identification).
- Boundary determination: after Exonerate gives provisional intron coordinates, `Adjust_all_intronic_junctions` shifts each junction by -6..+6 nt and scores candidates against type-specific splice-site models: MFannot_data/models/Splice/SpliceI.mod and SpliceII.mod (aligned 17-nt windows of known splice sites, e.g. from Allomyces cob/cox1/nad5 introns), built into HMM/PSSM via umac + hmmbuild ("AddSpliceScore"); group I vs II is taken from RNAweasel type. Lang 2023: Exonerate only has a single splice-site matrix, therefore MFannot re-adjusts boundaries; group I + II patterns pooled give "an indistinctive, almost neutral matrix". Boundaries "precisely inferred without transcript data" in most cases; RNA-seq of limited use (variable coverage at junctions).
- Files in MFannot_data/models/Erpin_models/Introns (17 .epn): A, Ader, B-327, B-alt, B-ins, B-yeast, Bder1, Bder2 (older group I models), IA1/IA3/IB/IB3/IC1/IC2/ID "-final-Dec2021/Jan2022" (Prince 2022), domV-cp-comp, domV-mito-521 (group II domain V). Other: rnpB, 5S, rns, tRNA models; CM_models has only ssrA.cm. (GitHub API listing, verified.)
- Known limitations (Lang 2023): "optimized for eukaryotes other than bilaterian animals" (so bilaterian mtDNA is out-of-scope but cnidarian/sponge/placozoa are non-bilaterian); not all introns detected, expert curation needed; ERPIN can't find "derived" introns lacking typical core elements; rRNA introns "just detected without positioning them in a proper gene model"; twintron detection only planned; cites MITOS2 as unable to model introns. ERPIN profile hits: IA1 960, IA3 78, IB 3582, IB3 202, IC1 337, IC2 948, ID 1105 in 662 fungal mtDNAs; 0.7% conflicts, 97% of those IB/IB3 (Prince 2022). Group II found with a single search on domains V+VI (Lang 2007). Group I subgroup IE and IA2/IC3 not modelled in Prince 2022 (as far as the fetched text shows).
- Availability: web https://megasun.bch.umontreal.ca/apps/mfannot/ ; code https://github.com/BFL-lab/Mfannot (GPL-3.0, last push 2023-10-02; Docker nbeck/mfannot; also on CBRAIN); RNAweasel https://github.com/BFL-lab/RNAweasel (no license in GitHub metadata; last push 2022-02-05; README warns of hard-coded paths; web server also exists). Data bundle: github.com/BFL-lab/MFannot_data. Maintenance: low-frequency; paper 2023.
- Citations:
  * Lang BF, Beck N, Prince S, Sarrasin M, Rioux P, Burger G. 2023. Mitochondrial genome annotation with MFannot: a critical analysis of gene identification and gene model prediction. Front Plant Sci 14:1222186. DOI 10.3389/fpls.2023.1222186 (verified Crossref).
  * Lang BF, Laforest M-J, Burger G. 2007. Mitochondrial introns: a critical view. Trends Genet 23:119-125. DOI 10.1016/j.tig.2007.01.006 (verified Crossref). This is the RNAweasel paper (NOT an Annual Review).
  * Prince S, Munoz C, Filion-Bienvenue F, Rioux P, Sarrasin M, Lang BF. 2022. Refining mitochondrial intron classification with ERPIN: identification based on conservation of sequence plus secondary structure motifs. Front Microbiol 13:866187. DOI 10.3389/fmicb.2022.866187 (verified Crossref).
- Borrow: (1) type-specific 5'/3' splice-site PSSMs (SpliceI/SpliceII.mod, and ±6 nt scan around Exonerate boundary) are directly reusable as a boundary-refinement step; (2) the ERPIN group I subgroup profile set (IA1..ID) gives a subgroup label that Rfam RF00028 cannot.

## 2. MITOS / MITOS2 (Bernt, Donath, Jühling ... Leipzig)
- Intron types: NONE annotated. Lang 2023 (Front Plant Sci) explicitly cites MITOS2 (Donath 2019) as unable to model introns; Lang 2023 also notes that introns, though rare in metazoans, occur in e.g. corals and sponges and that MITOS handles those poorly. MITOS GitLab README/CHANGELOG (mitos2 branch) contain no mention of "intron" (grep, verified). The Donath 2019 NAR paper's visible text has no intron statement (first 100k chars read via WebFetch; not exhaustive).
- Method: BLAST/HMM-based protein-gene search (profile HMMs), CM for tRNA/rRNA (Infernal), then gene-boundary refinement of protein-coding genes; metazoan-tailored. Gene models are contiguous (single exon) so a group I/II-interrupted cox1 is annotated as fragments or misses exons (inference from design; unverified in primary source).
- Availability: web http://mitos2.bioinf.uni-leipzig.de ; Galaxy EU (tool mitos2 2.1.7+galaxy1); conda `bioconda::mitos`, `pip install mitos`; GitLab https://gitlab.com/Bernt/MITOS , MIT licence, last activity 2025-12-20 (maintained).
- Citations: Bernt M et al. 2013 MITOS: improved de novo metazoan mitochondrial genome annotation. Mol Phylogenet Evol 69:313-319. DOI 10.1016/j.ympev.2012.08.023 (Crossref-verified DOI). Donath A et al. 2019 Improved annotation of protein-coding gene boundaries in metazoan mitochondrial genomes. Nucleic Acids Res 47:10543-10552. DOI 10.1093/nar/gkz833 (Crossref-verified DOI).
- Borrow: nothing for introns; useful only as the contiguous-gene baseline and to find exon1/exon2 stubs of an interrupted gene (hits split around an insertion).

## 3. General organelle annotators (reference-homology based; no intron-class models)
Common point: none of these detects introns de novo or classifies them as group I/II. Introns = gaps between exons inferred from alignment to curated reference genes (BLAST/BLAT/Exonerate/GeneWise); boundaries are only as good as the reference annotation. Lang 2023 states Mitofy, AGORA and GeSeq were optimised for plant organelle genomes.

### GeSeq (MPI-MP Golm; Tillich et al. 2017)
- Types: plastid (main), plant mito, also non-green mito if reference set supplied (paper: "with an appropriate reference set ... also annotates mitochondria genomes from non-green species, such as mammals").
- Method: translated BLAT (BLATx) for CDS, BLATn for RNA/DNA; optional HMMER profile HMMs (plastid CDS/rRNA), tRNAscan-SE (COVE mode for tRNA introns) and ARAGORN; user-selectable references (NCBI RefSeq or upload). Intron-containing genes: exon-intron positions come from the BLAT hits of the references ("works well for the vast majority of spliced genes"). Fails on tiny exons (<8 bp, e.g. petB/petD exon 1); over-annotates introns in fast-evolving genes (ycf1/2); trans-spliced genes (rps12) need manual curation.
- Boundary rule: none beyond alignment edges; no splice-site/IBS-EBS/omegaG logic found in the paper text (grep of "intron": only RefSeq error remarks, BLAT, tRNAscan). The paper text contains no mention of group I/II (verified by grep of Europe PMC full text).
- Availability: web server https://chlorobox.mpimp-golm.mpg.de/geseq.html (free; paper CC BY-NC); stand-alone not offered as far as seen (unverified); maintained (still online).
- Citation: Tillich M et al. 2017 GeSeq - versatile and accurate annotation of organelle genomes. Nucleic Acids Res 45:W6-W11. DOI 10.1093/nar/gkx391.
- Borrow: the "curated reference set per lineage" idea: if we build a small curated reference of metazoan mt genes with known intron positions (cnidarian cox1/nad5), a BLAT/Exonerate run against it reproduces intron positions without needing RNA models.

### AGORA (Dongguk Univ.; Jung et al. 2018)
- Types: any mito/plastid genome; BLAST-based homology + clustering with references (NCBI or user); "gene annotation of a genome with an exon-intron structure within a gene" available (abstract).
- Boundaries: from BLAST HSP clustering vs reference; no intron-class model.
- Availability: web https://bigdata.dongguk.edu/gene_project/AGORA/ (HTTP 200 on 2026-10-10); python+php; no source repo found (unverified). Last substantive update unknown (unverified).
- Citation: Jung J, Kim JI, Jeong YS, Yi G. 2018. AGORA: organellar genome annotation from the amino acid and nucleotide references. Bioinformatics 34:2661-2663. DOI 10.1093/bioinformatics/bty196 (verified Crossref).
- Borrow: little; same idea as GeSeq.

### DOGMA (Wyman, Jansen, Boore 2004)
- Types: plastid + ANIMAL mitochondrial genomes (not plant mito). BLAST vs custom DB of reference genes + tRNA secondary-structure base-pairing for animal mt tRNAs; web GUI for manual editing. No intron-specific method; manual editing of exon boundaries (abstract).
- Availability: https://dogma.ccbb.utexas.edu (web, legacy; not updated in years - unverified).
- Citation: DOI 10.1093/bioinformatics/bth352 (verified).
- Borrow: nothing algorithmic.

### Mitofy (Alverson lab; plant mt)
- Annotates genes and tRNAs in seed-plant mt genomes (plus cp-derived sequences/repeats); hosted at https://dogma.ccbb.utexas.edu/mitofy/ . No formal methods paper; page cites Alverson AJ et al. 2010 Mol Biol Evol 27:1436-1448, DOI 10.1093/molbev/msq029 (verified). Intron handling: not documented in what I could read (unverified). Not applicable to metazoans.

### MitoFinder (Allio et al. 2020)
- Assembles + annotates mt genomes from reads/assemblies. Annotation: BLAST/tblastn vs closely related GenBank reference, tRNA via MiTFi (default)/ARWEN/tRNAscan-SE. Paper full text (Europe PMC PMC7497042) contains NO occurrence of "intron" (grep, verified); README grep also none. Assumes contiguous genes; intron-containing cox1 will be fragmented.
- Availability: https://github.com/RemiAllio/MitoFinder (last push 2025-09-02, maintained; own licence file). DOI 10.1111/1755-0998.13160 (verified).

### MitoZ (Meng et al. 2019)
- Assembly (SOAPdenovo-Trans / MEGAHIT) + annotation: PCGs by tBLASTn vs local protein DB + GeneWise 2.2.0 to set boundaries, start/stop refinement with mt genetic code; tRNA by MiTFi (CM); rRNA by Infernal. Paper full text (PMC6582343) and wiki (cloned; grep of *.md) contain NO "intron" (verified). Hence MitoZ output for an intron-containing animal mt genome will lack intron features; GeneWise could in principle model introns but MitoZ expects intronless PCGs (design inference - unverified).
- Availability: https://github.com/linzhi2013/MitoZ (GPL-3.0; v3.6 2023-04-14; last push 2024-11-06; bioconda/docker). DOI 10.1093/nar/gkz173 (verified).
- Relevance: your repo already has modules/genbank/05_mitoz.py; MitoZ annotation should be followed by an intron step (MFannot/Infernal) - MitoZ will not provide it.

### PGA (Qu et al. 2019, plastid) and CPGAVAS2 (Shi et al. 2019, plastid)
- PGA: "reverse query-subject" BLAST: reference plastome genes are the query, target plastome is the subject; "accurately identifies gene and intron boundaries as well as intron loss" (abstract); handles intron loss warnings (log e.g. "atpF lost intron"). Reference-gene exon junction logic; no group II models. GPL-3.0, last push 2020-10-29 (maintenance low). Citation: Qu XJ, Moore MJ, Li DZ, Yi TS. 2019. Plant Methods 15:50. DOI 10.1186/s13007-019-0435-7 (verified Crossref).
- CPGAVAS2: curated reference dataset of 43 plastomes checked with RNA-seq (TopHat --max-intron-length 2000 --microexon-search), special modules for tiny exons (petB/petD/rpl16) and trans-spliced rps12 from 2544-plastome pattern statistics. Citation: Shi L et al. 2019 NAR 47:W65-W73. DOI 10.1093/nar/gkz345 (verified Crossref). Web server (http://47.96.249.172:16019/analyzer/home - from memory, unverified).
- Borrow (CPGAVAS2): validating exon-intron borders with RNA-seq spliced alignments is the gold standard when RNA-seq exists; for mt introns the conserved-pattern statistics for tiny terminal exons could be mimicked for cnidarian cox1 exon 1/2 junctions.

## 4. Group I intron databases / classifiers

### 4a. GISSD (Zhou, Lu, Wu et al., Wuhan Univ.)
- Content: 1789 complete group I intron records (intron + 15 nt of up/downstream exon), pseudoknot-containing secondary structures (comparative analysis + MFE), covers all 14 subgroups with structure-based alignments and a consensus structure per subgroup; consensus structures were used to judge confidence of 20,085 group I introns found by INFERNAL and classify them into subgroups automatically (abstract). ~95% of the ~17,000 validated are IC3 in chloroplast tRNA-Leu (so little metazoan content).
- Method: manual structure-based alignment + Infernal; boundaries "Infernal hit only" (Sellés Vidal 2025 table) = imprecise for most of the 20,085.
- Availability: http://www.rna.whu.edu.cn/gissd/ ; Sellés Vidal 2025 says "as of July 2024 the resource is partially inaccessible"; so effectively not maintained.
- Citation: Zhou Y et al. 2008. GISSD: Group I Intron Sequence and Structure Database. Nucleic Acids Res 36(Database issue):D31-D37 (online Nov 2007). DOI 10.1093/nar/gkm766 (verified Crossref; authors Zhou Y, Lu C, Wu QJ, Wang Y, Sun ZT, Deng JC, Zhang Y).

### 4b. Sellés Vidal, Noma, Yokobayashi 2025 - comprehensive group I intron database (KEY RESOURCE)
- Content: 42,459 group I introns with "precise" boundaries from all NCBI NT (Feb 2024), each with subtype (14 subtypes: IA1, IA2, IA3, IB1, IB2, IB3, IB4, IC1, IC2, IC3, ID, IE1, IE2, IE3), host gene, organelle, 300 nt flanking exons, HEG ORFs (6900 introns), secondary structure. Rfam has 2611 group I seqs (not subclassified) and CRW 201 (their comparison table).
- Method: (1) Infernal 1.1.5 cmsearch with the Rfam group I CM (RF00028) --nohmmonly -E 1000 against NT -> 245,292 hits; (2) boundaries: take GenBank feature `intron` overlapping the Infernal hit by >=50 positions, or the gap between two consecutive parts of a compound CDS/exon location that overlaps the hit by >=50; choose candidate with largest overlap; (3) validity filter: not at entry ends AND the first nt of intron range (= last nt of 5' exon) must be U (conserved U-G pair); 16,427 hits rejected because they did not start with U -> 42,459 retained; (4) subtype by cmscan against 14 subtype CMs built from MSAs (cmscan --max), best score wins.
- Metazoan-specific finding: "The only three multicellular animal organism types found to have group I introns (placozoans, corals, and sponges) all contained mostly mitochondrial introns of subtype IB4"; same IB4 in placozoans and corals consistent with Placozoa+Cnidaria sister (hypothesis they cite).
- Availability: https://github.com/LaraSellesVidal/Group1IntronDatabase (tsv.xz database, homingEndonucleasesDF.tsv, subtype_CMs/ [14 .cm files verified by API listing], subtype_MSAs/, notebook with full workflow; last push 2025-01-09; no licence field in GitHub metadata - check before redistributing); web GUI https://online-group-1-intron-database.onrender.com ; base-pair-probability matrices at BioStudies S-BSST1399.
- Citation: Sellés Vidal L, Noma T, Yokobayashi Y. Accurate, comprehensive database of group I introns and their homing endonucleases. Bioinformatics Advances 5(1):vbaf020 (online Dec 2024/2025). DOI 10.1093/bioadv/vbaf020 (verified Crossref/Europe PMC; Crossref issued-year 2024, Europe PMC pubYear 2025).
- Borrow: (a) the 14 subtype CMs can be dropped into the existing Infernal step (cmscan) to give IA/IB/IC/ID/IE subtypes for each RF00028 hit - far better than RF00028 alone; (b) their boundary rule (exon-end must be U; intron 3' end usually G) is an easy sanity filter; (c) the database gives IB4 mt introns from corals/placozoans/sponges as ready-made positive controls and as BLAST/nhmmer targets for cox1/nad5 introns.

## 5. Rfam intron-related families (Rfam 15.1, released 2026-01-16; 4227 families; parsed from ftp family.txt.gz, type = "Intron;")
Verified directly from the Rfam FTP family table (full list of type=Intron families; there are 17):
- RF00028 Intron_gpI "Group I catalytic intron": seed 12, full 5602, CM length 253, GA 49.90; structure source PMID:2197983 = Cech TR 1990 Annu Rev Biochem 59:543, DOI 10.1146/annurev.bi.59.070190.002551. Comment: model "represents only this conserved core" (P1-P9; P4-P6 + P3-P9 domains). One generic model, NO subgroup (IA/IB/IC/ID/IE) models in Rfam. => hit != whole intron: ORF insertions in loops (P1/P2/P6/P8/P9 loops), P1 5' end and P9.0/P10 3' end are not delineated reliably.
- RF00029 Intron_gpII "Group II catalytic intron": seed 92, full 49,099, CM length 77, GA 39.90. Comment: "This model and alignment represents only domains V and VI" - i.e. only the 3' terminal ~77 nt region of the intron; seed source PMID:11726522 = Chu VT, Adamidi C, Liu Q, Perlman PS, Pyle AM 2001 EMBO J 20:6866, DOI 10.1093/emboj/20.23.6866 (verified via Europe PMC); structure Predicted (PFOLD). Therefore the 5' boundary (domain I, EBS1/2) and the ORF in dIV must be located by other means.
- RF01998 group-II-D1D4-1 (seed 237/full 2508, clen 84); RF01999 -2 (144/1231, 118); RF02001 -3 (406/4274, 170); RF02003 -4 (90/840, 138); RF02004 -5 (139/720, 201); RF02005 -6 (174/1617, 225); RF02012 -7 (244/1296, 151). Author Weinberg Z, Gardner PP; structure "Predicted; Weinberg Z"; RF01998 has 1144 species. These seven "D1-D4" families are 7 separate CMs of the 5' half of group II introns (D1-D4 region; sub-types not named in the table). NOW VERIFIED: the Rfam comment text of RF01998 is copy-pasted from RF00029, but Presence of group II introns in phage genomes (Nucleic Acids Res 2025, DOI 10.1093/nar/gkaf761; Europe PMC PMC12350094) states: Rfam has 8 group II fragment models; RF00029 = 3' D5/D6 region (most conserved); the 5' end D1-D4 (variable across classes) is represented by SEVEN models grouped in Rfam clan CL00102 (group-II-D1D4-1..7). Expected for a complete intron: a D1-D4 hit (any of 7) + a D5/D6 hit a few hundred nt (ORF-less) or ~1 kb (ORF-containing) downstream; upstream/downstream hits always within 2 kb. Their boundary rule: 3' splice site is closely determined by the D5/D6 (RF00029) hit; 5' splice site at the conserved GWYRG site in the vicinity upstream of the D1-D4 hits; further confirmed by stitching flanking exons and aligning to an intronless homolog.
- Plastid group II (authors Mehta D, Reis R, Hua J; plastid-specific, land-plant chloroplast): RF04333 Plastid-ycf3 (group II-D1), RF04334 Plastid-rpl16 (D1), RF04336 Plastid-petD (D5), RF04355 Plastid-atpF (D1), RF04356/04357/04358 Plastid-ndhA-ndhB-1/2/3 (D5), RF04359 Plastid-GIID1-clpP (D1). Not useful for animal mt.
- Not "Intron" type but relevant: RF01807 GIR1 branching ribozyme (group I-like ribozyme, Didymium; Rfam type Gene;ribozyme, full 0); RF03094 LAGLIDADG-2 RNA (candidate structured RNA associated with LAGLIDADG genes; Weinberg; type Gene; sRNA; only 3 full hits) - not generally useful.
- Related by name only (do not use for introns): spliceosomal snRNAs U1/U2/U4/U5/U6/U7/U11/U12, RT-n RNAs (reverse-transcriptase-associated candidate RNAs), sisRNA (stable intronic sequence RNA of Drosophila/EBV), lncRNA intronic regions.
- Practical consequence for our pipeline: with cmsearch RF00028/RF00029 we get structured-core hits, not intron coordinates. Coordinates must come from protein-gene gaps (MFannot/Exonerate), plus the splice rules in section 8. Additional CMs worth adding: Sellés Vidal's 14 group I subtype CMs (section 4b) and the D1D4 families above.

## 6. Group II intron resources and classifiers

### 6a. Zimmerly lab Database for (bacterial) group II introns (Univ. Calgary)
- Content: catalogue of full-length non-redundant BACTERIAL group II introns (~400 by 2011); organellar introns only as a "sampling" in two tables; refers users to GOBASE and FUGOID for organellar introns (so not a metazoan-mt resource). Data per intron: host gene, insertion site, DNA seq, IEP (RT) sequence and domain, RNA secondary structure; classification by RNA structure IIA/IIB/IIC and by IEP phylogeny (bacterial classes A-F, ML = mitochondrial-like (IIA structure), CL1/CL2 = chloroplast-like, bacterial C = IIC, rest IIB variants).
- Tools on site: (i) local BLAST to nearest database intron "useful for determining correct boundaries and secondary structure", (ii) BOUNDARY PREDICTION TOOL: predicts 5' and 3' intron boundaries in an input DNA based on sequence profiles of the intron-exon junctions for each subclass; conservative: on known introns 72% correct, 3% incorrect, 25% no prediction (Candales 2012). Needs a candidate intron region + folding to confirm.
- Availability: http://webapps2.ucalgary.ca/~groupii/index.html (could not retrieve the page in this session: HTTP 502/empty via proxy => current availability UNVERIFIED; earlier Wikipedia/Database Commons list it). Not maintained since ~2012-2016 (inference; unverified).
- Citations: Candales MA, Duong A, Hood KS, Li T, Neufeld RAE, Sun R, McNeil BA, Wu L, Jarding AM, Zimmerly S. 2012. Database for bacterial group II introns. Nucleic Acids Res 40:D187-D190. DOI 10.1093/nar/gkr1043 (verified). Dai L et al. 2003. Database for mobile group II introns. NAR 31:424-426. DOI 10.1093/nar/gkg049 (verified Crossref; first author Dai L).
- Classification papers: Toor N, Hausner G, Zimmerly S. 2001. Coevolution of group II intron RNA structures with their intron-encoded reverse transcriptases. RNA 7:1142-1152. DOI 10.1017/s1355838201010251 (verified Crossref). Simon DM, Kelchner SA, Zimmerly S. 2009. A broadscale phylogenetic analysis of group II intron RNAs and intron-encoded reverse transcriptases. Mol Biol Evol 26:2795-2808. DOI 10.1093/molbev/msp193 (DOI verified). Simon DM et al. 2008. Group II introns in Eubacteria and Archaea: ORF-less introns and new varieties. RNA 14:1704-1713. DOI 10.1261/rna.1056108 (DOI verified). Zimmerly S, Semper C. 2015. Evolution of group II introns. Mobile DNA 6:7. DOI 10.1186/s13100-015-0037-5 (DOI verified).
- Borrow: the boundary logic (subclass-specific junction profiles + nearest-relative alignment) is exactly what MFannot's SpliceII.mod does; the ML/IIA vs CL vs IIB label from the RT (maturase) tree is a cheap sub-classifier if the intron carries an ORF.

### 6b. Titov et al. 2019 - structure-based finder for group II introns in organelle genomes
- Method: builds explicit secondary-structure models of all domains (DI-DVI) incl. EBS1-IBS1/EBS2-IBS2 (and beta-beta' pseudoknot) from a 27-sequence training set, scans the 10,130 eukaryotic (organellar) RF00029 sequences for thermodynamically stable DI-like structures, then checks YADD / conserved RT motifs; sub-types IIA/IIB; 5' splice site consensus found "GUGCG" (IIA, with YADD) or rare "UUGCG" (Magnoliopsida ORF-less IIA). Argues Rfam (D5-D6 only) "may contain false-positives".
- Targets plants/fungi organelles (no metazoan focus); output/data on figshare (collections of dot-bracket structures). Not packaged as maintained software (no tool repo seen - unverified).
- Citation: Titov I, Kobalo N, Vorobyev D, Kulikov A. 2019. A bioinformatic method for identifying group II introns in organella genomes. Front Genet 10:1135. DOI 10.3389/fgene.2019.01135 (verified Crossref).
- Borrow: use of IBS/EBS complementarity + YADD/RT-motif spacing (distance from YADD to intron start) as false-positive filter for RF00029 hits.

### 6c. Group II intron IEP (RT/maturase) searches
- Pfam RVT_1 PF00078 (and Intron_maturas2 PF01348 / HNH) used with hmmsearch to find intron-encoded RT; in phage paper PF00078 was used and hits were reconciled with D1-D4/D5-D6 CM hits within 3 kb. (PF accession numbers from the phage paper only for PF00078; PF01348/PF01844 from memory - unverified.)

## 7. Group I subtype classification practice; ML/DL status
- Subtype scheme: group I = types IA-IE, 14 subtypes (IA1-3, IB1-4, IC1-3, ID, IE1-3) (Michel & Westhof 1990 J Mol Biol 216:585, DOI 10.1016/0022-2836(90)90386-z [DOI verified; that this paper defines the 14-subtype scheme is from memory - unverified]; Sellés Vidal 2025 uses the 14-subtype set; Nawrocki 2018 and Cinget 2020 text states five types A-E and fourteen subtypes). 
- Nawrocki EP, Jones TA, Eddy SR. 2018. Group I introns are widespread in archaea. Nucleic Acids Res 46:7970-7976. DOI 10.1093/nar/gky414 (verified). Used Infernal 1.1 with SUBTYPE-specific CMs "following Lang et al." because a single Rfam RF00028 alignment does not capture the structural diversity; found 39 archaeal group I introns. Method template for us: build/borrow subtype CMs -> cmscan -> best score.
- Cinget B, Belanger RR. 2020. Discovery of new group I-D introns leads to creation of subtypes and link to an adaptive response of the mitochondrial genome in fungi. RNA Biol 17:1252-1260. DOI 10.1080/15476286.2020.1763024 (verified). Used "homology search methods taking into account both conserved sequence and RNA secondary structure" (Infernal) on 169 fungal mt genomes: 216 new ID introns, 3 ID subtypes.
- Machine/deep learning: I found NO published ML/DL tool (2018-2026) dedicated to detecting group I/II introns in organellar genomes or predicting their 5'/3' boundaries (searches via WebSearch extended + web-search-prime on 2026-10-10; negative result, not proof of absence). Relevant adjacent literature only:
  * General RNA language models (e.g. RiNALMo, Penic et al., arXiv:2403.00043 [DOI of the journal version unverified]) report group I intron secondary-structure benchmarks (F1 0.66 on group I vs 0.54 RNAstructure per search snippet - unverified numbers), and a fine-tuned splice-site head, but that is for nuclear pre-mRNA-type splice sites, not self-splicing introns.
  * SpliceAI-type nuclear splice-site predictors are trained on GT-AG spliceosomal introns and would not transfer to group I/II rules (inference, unverified).
  * Reviews note CM-based methods generalise poorly to unseen RNA families (snippet from a 2025 ML-for-RNA-secondary-structure review; not read).
  * Conclusion: state of the art remains covariance-model/ERPIN profile search + splice-site PSSM + protein-spliced alignment (MFannot, Infernal+subtype CMs, Sellés Vidal pipeline). An ML approach would have to be trained on Sellés Vidal's 42,459 exon-flanked group I introns and Candales/Zimmerly/Rfam group II sets - feasible but unpublished for organelles (opportunity, not a tool).

## 8. Splice-site rules (for boundary prediction)
### Group I (self-splicing, two transesterifications with exogenous guanosine)
- 5' splice site: the last nucleotide of the 5' exon is a U (consensus), which pairs with a G in the internal guide sequence (IGS) of P1 forming the conserved G·U wobble ("U:G pair at the 5' SS") that defines the splice site; exceptions exist (Diderma S529 inserted after G, U:G replaced by G:C pair, still self-splices). Source: Hedberg A, Johansen SD 2013 Mobile DNA 4:17, DOI 10.1186/1759-8753-4-17 (text verified in Europe PMC PMC3679873). Sellés Vidal 2025 uses this as a hard filter: 16,427 hits (for which GenBank-derived boundaries had been found) were rejected because the exon-end nucleotide was not U, leaving 42,459 (DOI 10.1093/bioadv/vbaf020, verified text).
- 3' splice site: the intron ends with a terminal G, ωG (omega G; "terminal sequence, most frequently the terminal G" in Sellés Vidal DB README), which binds the G-binding site in P7 and whose 3'-OH attacks the 5' splice site in the second step; rare variants ωA (Diderma L2066 still splices) (Hedberg & Johansen 2013). The intron 3' end typically is preceded by the P9.0 / P10 pairings with the 3' exon (P10 pairs IGS extension with 3' exon start; unverified here).
- Core: 9 paired regions P1-P9 forming P4-P6 and P3-P9 domains; conserved G-C pair at P7 (Hedberg & Johansen). HEG ORFs (LAGLIDADG/GIY-YIG) sit in peripheral loops (P1, P2, P6, P8, P9 depending on subtype), so the intron is longer than the Rfam core.
- Primary sources (all DOIs verified by Crossref): Cech TR 1990 Self-splicing of group I introns, Annu Rev Biochem 59:543, 10.1146/annurev.bi.59.070190.002551. Michel F, Westhof E 1990 Modelling of the three-dimensional architecture of group I catalytic introns based on comparative sequence analysis, J Mol Biol 216:585, 10.1016/0022-2836(90)90386-z. Burke JM et al. 1987 Structural conventions for group I introns, Nucleic Acids Res 15:7217, 10.1093/nar/15.18.7217. Cech TR, Damberger SH, Gutell RR 1994 Representation of the secondary and tertiary structure of group I introns, Nat Struct Biol 1:273, 10.1038/nsb0594-273. Damberger SH, Gutell RR 1994 A comparative database of group I intron structures, NAR 22:3508, 10.1093/nar/22.17.3508 (this is the CRW group I database). Haugen P, Simon DM, Bhattacharya D 2005 The natural history of group I introns, Trends Genet 21:111, 10.1016/j.tig.2004.12.007.
- Implication for animal mtDNA: group I introns (IB4 in cnidarian/placozoan/sponge mt) reside in cox1 / nad5 / rnl etc.; the rule "5' exon ends in U, intron ends in G" gives only 1-2 candidate positions around the Exonerate boundary; combine with P1 IGS complementarity (IGS lies right at the 5' end of the intron, pairs 5-6 nt with the end of the 5' exon; as a scoring term, IGS-exon pairing ΔG).

### Group II
- Splicing at specific junction sequences: 5'GUGYG...AY3' (intron begins GUGYG; ends ...AY; Y = pyrimidine) for the vast majority of group II introns (Zimmerly & Semper 2015 Mobile DNA 6:7, DOI 10.1186/s13100-015-0037-5 - text verified: "5′GUGYG…AY3′"). Exceptions: a set of fungal IIB1 rRNA introns (mostly with LAGLIDADG IEP) splice 1-33 nt upstream of GUGYG due to altered IBS1-EBS1 and loss of EBS2/branch site; C.te.I1 of Clostridium tetani splices 8 nt upstream; ~12 class B introns with domain VII shift the 3' splice site ~50-70 nt downstream of the canonical AY at the end of DVI.
- Structure: intron RNA is ~500-900 nt core of a 2-3 kb sequence: first ~600 nt (D1-D4) and last ~100 nt (D5-D6 around the IEP in D4 loop); domain V = catalytic triad AGC (CGC in some); domain VI contains the bulged A (branch site; 2'OH attacks 5' splice junction). Exon recognition: IBS1-EBS1 (5' exon, 6 nt), IBS2-EBS2, IBS3-EBS3 and delta-delta' pairings; the combination differs among IIA/IIB/IIC (Zimmerly & Semper 2015).
- Classes: ribozyme classes IIA, IIB (IIB1, IIB2), IIC (bacteria only); IEP classes ML (IIA structure; found in mitochondria), CL1/CL2 (chloroplast), A-F (bacteria). In organelles only ML and CL IEP classes exist.
- Organellar 5' splice site: "GUGCG" (all IIA with YADD in Rfam eukaryotic set), rare "UUGCG" in Magnoliopsida ORF-less IIA introns (Titov 2019).
- Primary sources: Michel F, Umesono K, Ozeki H 1989 Comparative and functional anatomy of group II catalytic introns - a review, Gene 82:5-30, DOI 10.1016/0378-1119(89)90026-7 (verified). Michel F, Ferat JL 1995 Structure and activities of group II introns, Annu Rev Biochem 64:435, DOI 10.1146/annurev.bi.64.070195.002251 (verified). Lambowitz AM, Zimmerly S 2004 Mobile group II introns, Annu Rev Genet 38:1, DOI 10.1146/annurev.genet.38.072902.091600 (verified). Lambowitz AM, Zimmerly S 2011 Group II introns: mobile ribozymes that invade DNA, CSH Perspect Biol 3:a003616, DOI 10.1101/cshperspect.a003616 (verified). Pyle AM 2016 Group II intron self-splicing, Annu Rev Biophys 45:183, DOI 10.1146/annurev-biophys-062215-011149 (verified).
- Twintrons (group II inserted in group II/I) and trans-splicing group II (plant nad1/nad2/nad5) - plant-specific; not in animal mt.
- Note on MFannot's neutral splice matrix: because group I (U|...G) and group II (GUGYG...AY) rules are different, pooling gives a flat matrix; so MFannot first assigns the type via RNAweasel then uses SpliceI/SpliceII.mod separately.

## 9. Metazoan mitochondrial introns - what is known (all DOIs verified via Crossref/Europe PMC unless stated)
Headline: no single census of animal mt introns was found; the best synthesis is Lavrov & Pett 2016 (qualitative). Counts below are assembled from primary papers.
Review: Lavrov DV, Pett W. 2016. Animal mitochondrial DNA as we do not know it: mt-genome organization and evolution in nonbilaterian lineages. Genome Biol Evol 8:2896-2913. DOI 10.1093/gbe/evw195 (full text read via Europe PMC PMC5633667). Key statements: introns in nonbilaterian mtDNA first found in anthozoans, then demosponges, placozoans, homoscleromorph sponges; among bilaterians only in a few annelids. All hexacoral mt genomes contain a group I intron in nad5 and often another in cox1; the nad5 intron "encompasses at least 2 and as many as 15 standard mitochondrial genes" (+ORFs); one or two group I introns in cox1 of homoscleromorph Plakinidae; three different group I introns in cox1 of several demosponge groups; all placozoan mt genomes have 6-7 group I introns, cox1 split into exons with trans-splicing; up to four forms of group II in placozoans; two group II in demosponges (RT of probable red algal origin); group II in several annelids (only bilaterian example). NO introns in glass sponges, calcareous sponges, ctenophores, medusozoan cnidarians, myxozoans, most bilaterians, nor octocorals or Oscarellidae (both slow-evolving). Mutational-hazard explanation proposed for absence in fast-evolving lineages.

### Cnidaria (all group I; Hexacorallia only)
- Metridium senile (sea anemone): COI intron (encodes putative LAGLIDADG homing endonuclease, circularizes) and ND5 intron containing ND1 and ND3; the ND5 intron "ends with A" (not G). Beagley CT, Okada NA, Wolstenholme DR. 1996. PNAS 93:5619-5623. DOI 10.1073/pnas.93.11.5619.
- Acropora tenuis (Scleractinia): nad5 interrupted by a group I intron with 10 protein genes + rns, ~11.5 kb between exon boundaries; RT-PCR across the splice site. van Oppen MJH et al. 2002. J Mol Evol 55:1-13. DOI 10.1007/s00239-001-0075-0.
- Faviina corals cox1 group I intron (LAGLIDADG), in 13 of 41 genera / 20 of 73 species, different insertion site from anemone, similar to a sponge cox1 intron. Fukami H, Chen CA, Chiou CY, Knowlton N. 2007. J Mol Evol 64:591-600. DOI 10.1007/s00239-006-0279-4.
- Lophelia pertusa: ND5-717 complex group I intron (6460 bp) hosting 7 protein genes + 1 rRNA; "lacks the universally conserved omega-G at the 3' end"; vertical inheritance in hexacorals. Emblem A et al. 2011. Mol Phylogenet Evol 61:495-503. DOI 10.1016/j.ympev.2011.07.012.
- Actiniaria: ND5 intron hosting essential mt genes + COI intron with HEG in all six mtDNAs examined; HEG variants fused in-frame with upstream exons. Emblem A et al. 2014. Mol Phylogenet Evol 75:184-193. DOI 10.1016/j.ympev.2014.02.016.
- Corallimorpharia (Ricordea yuma, Amplexidiscus fenestrafer): ND5-717 giant group I intron 18.1-19.3 kb holding almost the entire mt genome in P8; removed by back-splicing from a permuted precursor (circular exon-containing intermediate); COI-884 also present. Chi SI, Dahl M, Emblem A, Johansen SD. 2019. BMC Mol Biol 20:16. DOI 10.1186/s12867-019-0134-y.
- Annotation-relevant: (i) ND5-717 intron can be >10-19 kb, with a permuted arrangement in Corallimorpharia, so default Exonerate `--maxintron` caps and linear exon order assumptions fail; (ii) ωG rule does NOT hold for ND5-717 (ends with A in Metridium; lacks ωG in Lophelia) - do not hard-filter on 3' G for hexacoral nad5.

### Porifera
- Tetilla sp. (Spirophorida) first sponge cox1 group I intron (1143 bp, LAGLIDADG; fungal donor proposed): Rot C, Goldfarb I, Ilan M, Huchon D. 2006. BMC Evol Biol 6:71. DOI 10.1186/1471-2148-6-71.
- Tetillidae: 6 of 17 cox1 sequences carry group I introns, 3 forms at cox1 alignment positions 714, 723, 870 with distinct structures/LAGLIDADG lineages: Szitenberg A, Rot C, Ilan M, Huchon D. 2010. BMC Evol Biol 10:288. DOI 10.1186/1471-2148-10-288.
- Aplysinella rhax (Verongida) first non-tetillid demosponge cox1 group I intron: Erpenbeck D, Aryasari R, Hooper JNA, Wörheide G. 2015. J Mol Evol 80:13-17. DOI 10.1007/s00239-014-9653-9.
- Agelas oroides, Cymbaxinella verrucosa, Axinella polypoides: first GROUP II introns in sponge cox1 (two different ones in C. verrucosa, related to red algal introns): Huchon D, Szitenberg A, Shefer S, Ilan M, Feldstein T. 2015. BMC Evol Biol 15:278. DOI 10.1186/s12862-015-0556-1.
- Scleritodermidae etc.: 95 specimens/11 genera group I; four types group I + two types group II known in demosponges; up to three HEG/RT ORFs; two introns in one cox1 always one active + one degenerating; Spirophorina = intron hotspot: Schuster A, Lopez JV, Becking LE, Kelly M, Pomponi SA, Wörheide G, Erpenbeck D, Cárdenas P. 2017. BMC Evol Biol 17:82. DOI 10.1186/s12862-017-0928-9.
- Note: Sellés Vidal 2025 DB classifies the mt introns of placozoans, corals and sponges mostly as subtype IB4.

### Placozoa
- Trichoplax adhaerens mtDNA 43 kb with several large introns/ORFs: Dellaporta SL et al. 2006. PNAS 103:8751-8756. DOI 10.1073/pnas.0602076103. Three more placozoan mtDNAs (32-37 kb) share several cox1 introns and a LAGLIDADG ORF: Signorovitch AY, Buss LW, Dellaporta SL. 2007. PLoS Genet 3:e13. DOI 10.1371/journal.pgen.0030013.
- Reanalysis: cox1 is discontinuous, joined by group I intron trans-splicing; claimed U-to-C editing: Burger G, Yan Y, Javadi P, Lang BF. 2009. Trends Genet 25:381-386. DOI 10.1016/j.tig.2009.07.003. Later RNA-seq found no support for the editing but a 1-bp (cytosine) micro-exon in cox1 flanked by conserved group I structures: Osigus HJ, Eitel M, Schierwater B. 2017. PLoS ONE 12:e0177959. DOI 10.1371/journal.pone.0177959. => 1-nt exons are invisible to Exonerate/BLAST-based exon finders; the 5' exon-end U rule interacts with the editing/micro-exon puzzle.
- Group I in placozoan rnl (16S) mentioned in a secondary summary - UNVERIFIED.

### Annelida (group II; the only bilaterians besides Bryozoa/mollusc)
- Nephtys sp. (Phyllodocida): first group II intron in a bilaterian, 1819 bp in cox1, ORF with RT/maturase; proposed recent HGT: Vallès Y, Halanych KM, Boore JL. 2008. PLoS ONE 3:e1488. DOI 10.1371/journal.pone.0001488. (At that time >900 complete animal mtDNAs and no other bilaterian introns.)
- Glycera fallax (2 introns I1, I2 in cox1) and G. unicornis (1) (Glyceridae; 2357-2468 bp): Richter S, Schwarz F, Hering L, Böggemann M, Bleidorn C. 2015. Genome Biol Evol 7:3443-3462. DOI 10.1093/gbe/evv224.
- Decemunciger sp. (Ampharetidae, Terebellida): introns in cox1 (1648 bp, intron maturase ORF), nad1 (390 bp), nad4 (262 bp) in all three genomes; palindromic ends; "first multiple introns in distinct genes in a bilaterian": Bernardino AF, Li Y, Smith CR, Halanych KM. 2017. Sci Rep 7:4295. DOI 10.1038/s41598-017-04094-w.
- Travisia sanrikuensis (Travisiidae, formerly within Opheliidae) + 5 undescribed Travisia spp.: degenerate group II introns in cox1 at the same position, 790-1386 bp (882 bp in T. sanrikuensis), RT/maturase ORFs in two species; begin 5'GCGCG and end AY3'; domains V and VI found by Mfold; first metazoan case of group II introns conserved across descendants: Kobayashi G, Itoh H, Kojima S. 2022. Sci Rep 12:4449. DOI 10.1038/s41598-022-08103-5. NB the 5' motif is GCGCG, a deviation from textbook GUGYG.
- Endomyzostoma sp. (Myzostomida) cox1 group II: listed in Jenkins 2022; primary source NOT identified (unverified).
- Bryozoa (Cheilostomatida) - bilaterian, colonial: 8 introns in complete mtDNA of Exechonella vieirai; 5, 17, 18 introns in partial mtDNAs of Parantropora penelope, Discoporella cookae, Cupuladria biporosa; RVT-IM IEPs; domains V+VI found by Rfam search in E. vieirai and P. penelope (none in the two cupuladriids); introns end YAY (IIA-like); annotation by MITOS + manual; phylogeny: multiple independent origins; Jenkins HL, Graham R, Porter JS, Vieira LM, de Almeida ACS, Hall A, O'Dea A, Coppard SE, Waeschenbach A. 2022. Sci Rep 12:10889. DOI 10.1038/s41598-022-14477-3. The same paper cites a mollusc Cucullaea labiata (Arcoida) cox1 intron (identified as group II in Kobayashi 2022) - primary report not located.
- Pattern noted by authors: taxa with introns have budding/regeneration (sponges, placozoans, annelids, bryozoans), consistent with germline access for HGT (Szitenberg 2010; Vallès 2008; Jenkins 2022 - hypothesis, not proven).
- Approximate tally (my compilation, not a published number): hexacoral lineages (Actiniaria, Scleractinia, Corallimorpharia, Zoantharia/Antipatharia: nad5-717 in all; cox1 in anemones/corallimorpharians/Faviina corals); sponges: group I at >=4 cox1 sites + 2 group II types in 6+ families; placozoans 6-7 group I (+group II) per genome in >=4 haplotypes; bilaterians: <=~6 annelid lineages (Nephtys, Glycera x2 spp., Decemunciger, Travisia x6 spp., Endomyzostoma), 4 bryozoans (5-18 introns each), 1 mollusc. Order of magnitude: a few hundred metazoan mt intron copies in total (estimate, unverified).

## 11. What we could borrow for the yzz pipeline (prioritised, my synthesis)
1. Add the 14 group I SUBTYPE CMs from github.com/LaraSellesVidal/Group1IntronDatabase (subtype_CMs/*.cm) to the Infernal step (cmscan best-score) -> IA/IB/IC/ID/IE labels; reported metazoan mt introns are mostly IB4 (placozoa, corals, sponges). Check the repo licence first (none in GitHub metadata).
2. Add the seven Rfam group-II 5' models (RF01998, RF01999, RF02001, RF02003, RF02004, RF02005, RF02012; clan CL00102) next to RF00029; report D1-D4 hit + D5/D6 hit pairs on the same strand within ~2 kb as one complete group II intron (method of Presence of group II introns in phage genomes, NAR 2025). RF00029 alone marks only the 3' ~77 nt; RF00028 only the group I core.
3. Boundary scoring: take Exonerate/BLAST gap as the seed, then scan +-6 nt (as MFannot does) and score with (a) group I: exon-end U (soft), intron-end G/A, IGS-exon pairing; (b) group II: 5' GUGYG-like (allow GCGCG, GUGCG, UUGCG) and 3' (Y/R)AY; make these soft penalties not hard filters because animal exceptions exist: hexacoral nad5-717 ends with A / lacks omega-G (Beagley 1996; Emblem 2011), Travisia group II start GCGCG (Kobayashi 2022), placozoan cox1 has a 1-nt C micro-exon (Osigus 2017).
4. Also reuse MFannot's SpliceI.mod/SpliceII.mod (GPL-3.0 data repo BFL-lab/MFannot_data) as PSSMs for the scan; it is the only ready-made, type-specific splice-site matrix pair found.
5. Validate calls by "stitching" flanking exons and comparing to an intronless homolog of the same gene (phage-paper approach; PGA/GeSeq-style reference homology); for cnidarian/sponge cox1 use known insertion sites (cox1-714/723/870 in tetillid sponges; COI-884 in anemones/corallimorpharians; ND5-717 in hexacorals) as sanity checks that the intron is at a known site.
6. Exonerate settings: raise --maxintron for hexacoral nad5 (introns of 6-19 kb, permuted in Corallimorpharia) and allow micro-exons (1-nt) only through RNA-seq or sibling-species alignments.
7. Use Sellés Vidal DB (42,459 introns with 300 nt flanking exons, HEG ORFs) as a BLAST/nhmmer target to find group I introns whose CM score falls under the Rfam GA 49.9.
8. Lightweight ORF layer: intron-encoded ORFs (LAGLIDADG/GIY-YIG for group I, RT/maturase [Pfam PF00078 RVT_1] for group II) via hmmsearch on all six frames with the mt genetic code (and the other genetic codes, as Sellés Vidal did) - MFannot uses BLAST vs an intronic ORF library instead.
9. No ML model to borrow (section 7).
