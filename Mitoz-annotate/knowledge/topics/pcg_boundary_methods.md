# How mitochondrial annotators decide protein-coding gene (PCG) boundaries

Scope: how start codon, stop codon (complete and incomplete T/TA), overlaps (atp8/atp6, nad4l/nad4) and short divergent genes (atp8, nad6) are decided by MITOS2, MitoZ 3.6, MFannot, GeSeq, MitoAnnotator, MitoFinder, MitoHiFi, MitoFlex, DeGeCI and the literature, and which ideas can go into our pipeline. Genetic-code tables and start/stop frequencies in RefSeq are in topics/genetic_codes_start_stop.md; tool details in tools/mitos2.md, tools/mitoz.md, tools/mfannot.md, tools/mitofinder.md (not repeated here unless needed).

Every bullet ends with a source: `(path:line)`, `(doi:...)`, `(https://...)` or 未确证. Evidence labels inside bullets: [code] read in source, [paper] stated in a paper, [our run] measured by us on 2026-10-20, [inference] derived by us, not tested. Path prefixes: `mitos/...` = `/root/miniconda3/envs/mitos/lib/python3.12/site-packages/`; `mitoz/...` = `/root/miniconda3/envs/mitoz3.6/lib/python3.8/site-packages/`; `refseq89m/...` = `/opt/mitos_refs/refseq89m/`; `Mfannot/mfannot` = https://github.com/BFL-lab/Mfannot HEAD 0990c85; `MitoFinder/...` = https://github.com/RemiAllio/MitoFinder clone; `knowledge/...` = this knowledge directory (our experiment files are in `knowledge/experiments/mitos2_pcg/`, produced by `compare_mitos2_refseq.py`, `overlap_junctions.py`, `mitoz_vs_ncbi_by_gene.py` and `atp8_nterm.py`, which share `pcg_names.py`).

Our test set (used in sections 1, 4, 5): six RefSeq genomes NC_000931.1 (Platynereis, code 5), NC_012920.1 (human, 2), NC_024511.2 (Drosophila, 5), NC_001328.1 (C. elegans, 5), NC_001566.1 (Apis, 5), NC_001453.1 (sea urchin, 9) annotated with `runmitos_fast.py --no_sensitive -r refseq89m` plus proteins (`--rrna 0 --intron 0 --oril 0 --orih 0`); RefSeq is not a gold standard (see topics/genetic_codes_start_stop.md), so "differs from RefSeq" means "differs", not "wrong".

## 1. MITOS2 (mitos 2.1.10)

### 1.1 Pipeline up to the boundary step
- Protein search is one `blastx -query_gencode <code> -outfmt 6 -seg no -num_alignments 1000000000` per gene family against `featureProt/<gene>.fas`, with no `-evalue` argument, i.e. BLAST's default threshold of 10 at this stage [code] (mitos/update/__init__.py:555-566)
- Reference families are large: refseq89m holds 7,641 atp8, 8,011 atp6, 8,000 nad4l, 8,024 nad6 and 8,022 cox1 sequences (`grep -c '>'`), so atp8 has 95 % of the atp6 reference depth [our run] (refseq89m/featureProt/atp8.fas:1)
- Hits are kept only if -log10(E) >= `--evalue` (default 2, i.e. E <= 0.01); E = 0 is set to 200 [code] (mitos/blast/__init__.py:1587-1592) (mitos/scripts/runmitos.py:1203-1210)
- Per nucleotide position and reading frame the hits are summed into a "quality" (sum of -log10 E), a height, and two relative query positions (distance from the start and from the end of the reference protein) [code] (mitos/blast/__init__.py:1298-1470) (mitos/blast/__init__.py:38-135)
- Initial hit = a stretch of consecutive positions in one frame, trimmed to positions with quality >= `--cutoff` (0.5) x the stretch maximum [code] (mitos/blast/__init__.py:872-958) (mitos/scripts/runmitos.py:1212-1220)
- Order inside `blastx()`: initial hits, copy/part numbering, start/stop optimisation of the first and last part of each copy, then greedy overlap resolution, then copy/part again; start/stop are therefore optimised before overlaps are resolved and without knowledge of neighbouring PCGs (only tRNAs are known) [code] (mitos/blast/__init__.py:506-556)
- The "forbidden" regions given to the optimiser are the best (mito==2) tRNA hits of the same run; with `--trna 0` the list is empty and a PCG can be extended over a tRNA [code] (mitos/scripts/runmitos.py:340-346)

### 1.2 The start/stop model (the part worth copying)
- The new model of Donath et al. maximises delta_s * phi_s * delta_e * phi_e * lambda(length): delta = distance of the candidate from the estimated gene boundary in the reference protein, phi = empirical codon probability, lambda = empirical length p-value [paper] (doi:10.1093/nar/gkz833)
- Candidate range: the "plateau" of the hit is shrunk to its middle, then the search walks outward in 3-nt steps until the first in-frame stop codon of the NCBI table or until the extension would completely cover a best tRNA; start candidates therefore lie anywhere between the upstream stop and the middle of the BLAST hit, not within a fixed +-6 aa window [code] (mitos/blast/__init__.py:1748-1771) (mitos/blast/__init__.py:1780-1835) (mitos/trna/__init__.py:146-155)
- Only codons with a learned frequency > 0 for that gene and code are candidates (starts below 0.01 were removed when the statistics were built; inner-codon stops with frequency >= 0.001 ignored) [code] [paper] (mitos/blast/__init__.py:1904-1941) (doi:10.1093/nar/gkz833)
- Incomplete stops are scored like complete ones with a malus: a codon starting with TA (not TAA/TAG) uses the learned "TAN" frequency x 1/3, a codon starting with T uses "TNN" x 1/12 (chance-correction: 4 and 16 times more likely than a full stop); the feature then ends after the T or TA, so its length is 3n+1 or 3n+2 [code] [paper] (mitos/blast/__init__.py:1921-1930) (mitos/blast/__init__.py:2057-2058) (doi:10.1093/nar/gkz833)
- delta_s/delta_e = 1 - relative position in the reference protein at that nucleotide; candidates outside the aligned part inherit the value of the aligned end, so extending beyond the hit costs nothing in delta and is decided by codon frequency and length p-value (the paper says delta = 1 outside the reference interval, the BLAST code uses 1 - qm) [code] [paper] (mitos/blast/__init__.py:1985-2018) (doi:10.1093/nar/gkz833)
- lambda = learned length p-value of (code, gene, length in nt); a length absent from the table gives 0 and removes the candidate [code] (mitos/blast/__init__.py:2020-2040)
- The product is `codp * dend * degmal * lenpv` over start and stop; the first strictly better candidate wins and candidates are enumerated outside-to-inside, so exact ties go to the longer gene; the `quality` criterion is computed but not used in the product [code] (mitos/blast/__init__.py:1952-1963) (mitos/blast/__init__.py:2054-2126)
- If no candidate has phi > 0 the BLAST/HMM boundaries are kept unchanged [code] [paper] (mitos/blast/__init__.py:2126-2140) (doi:10.1093/nar/gkz833)
- Learned statistics are per gene and per code: `auxinfo.json` has start/stop tables for codes 2, 4, 5, 9, 13, 14, 24 in "learned" ("5*") and NCBI-uniform ("5") versions; `--ncbicode` switches to the uniform one (code 5: each of ATA ATC ATG ATT GTG = 0.167, TAA = TAG = 0.5) [code] (refseq89m/auxinfo.json:1) (mitos/scripts/runmitos.py:113-160)
- Example learned values, code 5*: atp8 starts ATT .371, ATG .224, ATA .182, ATC .181, GTG .027 and stops TAA .857, TAG .109, TNN .034; atp6 starts ATG .738, ATA .149, ATT .083; nad4 stops TAA .437, TNN .321, TAG .177, TAN .065 [our run] (refseq89m/auxinfo.json:1)
- Example learned values, other codes: code 2* atp8 start ATG 1.0 and atp6 ATG .972; code 9* atp8 GTG .526, ATG .456; code 4* nad6 ATG .532, GTG .219, ATA .209 [our run] (refseq89m/auxinfo.json:1)
- Example length prior, code 5 atp8: p-value 0.86 at 160 nt, 0.40 at 163 nt, 0.21 at 168 nt, 0.020 at 200 nt (peak 159-161 nt); code 9 atp6: peak 517-518 nt (0.97) but only 0.107 at 696 nt [our run] (refseq89m/auxinfo.json:1)
- Paper results: start/stop agree with RefSeq in 77.5 % / 75.8 % of PCGs of genomes new in RefSeq 89, the older +-6 aa method differed in more than 40 %; 12.4 % (6,725 of 54,045) of PCGs differ by 1-2 bp, mainly because the new method annotates the last base of incomplete stops; precision is clearly better for vertebrates (code 2) than for codes 4, 5, 9, 13 because the training set is vertebrate-dominated [paper] (doi:10.1093/nar/gkz833)

### 1.3 Overlaps, copies and parameters
- After optimisation hits are sorted by score; a hit overlapping a better-scoring hit by more than `--finovl` (CLI default 50 nt) is clipped if it has the same name and a score ratio within `--clipfac` (10), otherwise it is deleted completely; so a low-scoring short gene such as atp8 overlapping a neighbour by more than 50 nt would be lost (inference: not observed in our six genomes) [code] (mitos/blast/__init__.py:2355-2392) (mitos/scripts/runmitos.py:1156-1162)
- Overlaps up to 50 nt survive: MITOS2 reproduced 5 of the 6 + strand overlaps of our genomes with exact coordinates (human atp8/atp6 46 nt and nad4l/nad4 7 nt, Drosophila atp8/atp6 7 nt, Apis atp8/atp6 19 nt, Platynereis nad4l/nad4 7 nt); the sixth (sea urchin atp8/atp6, 10 nt) was lost because the atp6 start moved 177 nt inside [our run] (knowledge/experiments/mitos2_pcg/results.tsv:1)
- The paper states the method "allows for large overlaps" and quotes atp8/atp6 = 46 bp in human, and 2,085 RefSeq 63 annotations with overlaps > 10 bp [paper] (doi:10.1093/nar/gkz833)
- Round 2 (default; skipped by `--best`) appends weaker hits of the same name when conflict-free; on Apis NC_001566.1 the default run reports a second atp8 (90 nt, minus strand, 14722..14811) that RefSeq does not have, and `--best` removes it with the 13 other PCGs unchanged; the 2013 MITOS made the same kind of error (a second 105-bp ATP8 in the D-loop of Nesiarchus nasutus) [code] [our run] [paper] (mitos/scripts/runmitos.py:685-721) (knowledge/experiments/mitos2_pcg/results.tsv:1) (doi:10.1093/molbev/mst141)
- Proteins are appended first in the first-round feature order (prot, tRNA, rRNA, ...), so a tRNA that overlaps an accepted PCG by more than `--finovl` is rejected into `ignored.mitos`, not the PCG [code] (mitos/scripts/runmitos.py:494) (mitos/mergefeature/__init__.py:14-141)

### 1.4 How atp8 is found
- There is no atp8-specific code: atp8 is one of 13 families in `metazoa_prot` and goes through the same BLASTX, E <= 0.01 filter and start/stop model; what differs is only its learned codon and length tables (above) [code] (mitos/mito/__init__.py:81-95) (refseq89m/auxinfo.json:1)
- Hence a very divergent atp8 is lost when no BLASTX hit reaches E <= 0.01; flatworm atp8 had BLASTP E-values of 0.027-0.22 against nr and the 2013 MITOS did not annotate it in 5 of 6 genomes, so a cutoff of E <= 0.01 would also drop them (different database and program, so only indicative) [paper] [inference] (doi:10.1186/s12864-017-3807-2)
- The profile-HMM route (`--alarab`, hmmscan `--domE 0.999999 --max`, E threshold 0.006) needs `featureProtHMM/`, which refseq89m does not contain, so it is not available to us [code] (mitos/protfeat/__init__.py:67-92) (mitos/protfeat/__init__.py:449) (mitos/scripts/runmitos.py:1346-1349)
- In our six genomes atp8 was found in all five that have it, with 5' end identical to RefSeq in 5/5 and 3' end identical in 4/5 (Platynereis: MITOS2 ends 5 nt later at a complete TAA where RefSeq ends GAT), and correctly not found in C. elegans, which lacks atp8 [our run] (knowledge/experiments/mitos2_pcg/results.tsv:1)

### 1.5 Our measurement against RefSeq (76 gene comparisons)
- Over the 13 PCGs of the six genomes (76 comparable loci; one absent atp8 and one origin-wrapping cob excluded): 5' end identical in 50 (66 %), 3' end in 59 (78 %), both in 39 (51 %); for atp8/atp6/nad4l/nad4 alone (23 loci) 16 (70 %), 21 (91 %) and 14 (61 %) [our run] (knowledge/experiments/mitos2_pcg/results.tsv:1)
- Direction of 5' errors: MITOS2 starts later (shorter gene) in 17 of 26 differing 5' ends and earlier in 9; of the 26, 11 have a MITOS2 start codon with higher learned frequency than the RefSeq start codon (e.g. human nad1 RefSeq ATA p=0.039 vs MITOS2 ATG p=0.921, 6 nt inside), 15 use the same codon type at another position [our run] (knowledge/experiments/mitos2_pcg/results.tsv:1)
- Direction of 3' errors: 20 of the 76 RefSeq CDS have a length that is not a multiple of 3 (incomplete T/TA stop); MITOS2 reproduced 4 of them exactly, ended later in 15 and earlier in 1; all 15 later ends are such loci, 12 extended 1-20 nt to an in-frame complete stop that can overlap the next tRNA (Platynereis cox1 +17, nad6 +20; Drosophila nad5 +20) and 3 chose another incomplete stop 1-28 nt later; MITOS2 itself wrote an incomplete stop in only 9 of 76 loci [our run] (knowledge/experiments/mitos2_pcg/results.tsv:1)
- Reason for the stop bias [inference from the tables]: complete TAA has learned frequency 0.80-0.86 for atp8, atp6, nad4l and nad6 (0.44 for nad4) while a single-T stop is scored TNN x 1/12 (atp8 0.034/12 = 0.003), so a complete stop wins unless delta or lambda compensate (refseq89m/auxinfo.json:1) (mitos/blast/__init__.py:1928-1929)
- Sea urchin (code 9) is the worst case: 7 of 12 compared genes have a 5' end 27-201 nt inside RefSeq (atp6 +177, nad5 +201, cox3 +72, cox2 +48, nad4 +30, nad4l +27, nad6 +27); in all 7 the RefSeq boundaries were among MITOS2's own candidates but lost because the learned length p-value favoured the shorter gene (atp6 lambda 0.107 vs 0.970, product 0.053 vs 0.369; nad6 0.130 vs 0.840; nad4 0.260 vs 0.694; nad5 0.367 vs 0.686) [our run] (knowledge/experiments/mitos2_pcg/lenpv_competition_NC_001453.1.tsv:1) (knowledge/experiments/mitos2_pcg/stst_atp6_NC_001453.1.tsv:1)
- Why lambda misleads there [inference]: the length prior is per genetic code, not per clade, and the paper notes that codon and length statistics vary between taxa sharing a code; the composition of the code-9 training set was not inspected (未确证) (doi:10.1093/nar/gkz833)
- Cost: with proteins on, MITOS2 took about 5 min per genome (six genomes in parallel on 16 cores) against about 8 s for the tRNA-only fast mode (knowledge/tools/mitos2.md:32) [our run] (knowledge/experiments/mitos2_pcg/results.tsv:1)

## 2. MitoZ 3.6 (annotate module)

Detailed algorithm and known bugs are in tools/mitoz.md (lines 17-31 and 44-58 there); this section adds what matters for boundaries, overlaps and atp8.

### 2.1 Where a gene is found, and where atp8 fails
- Gene detection = `tblastn -evalue 1e-5 -seg no -db_gencode <code>` of the clade protein DB against the genome, then identity > 30 % (column 3 of `-outfmt 6`), SOLAR score >= 25, aligned part >= 25 % of the query; these gates apply to every gene, there is no gene-specific setting [code] (mitoz/annotate/script/MT_annotation_BGI_V1.32/MT_annotation_BGI.pl:145) (mitoz/annotate/script/MT_annotation_BGI_V1.32/MT_annotation_BGI.pl:276-290) (mitoz/annotate/script/MT_annotation_BGI_V1.32/MT_annotation_BGI.pl:292-312)
- The script header records that version 1.2 lowered the tblastn E-value to 1e-2 for ATP8 ("Optimized ATP8 annotation") and version 1.32 went back to a global 1e-5 because the lower threshold produced false positives; the extra ATP8 sensitivity was deliberately given up [code] (mitoz/annotate/script/MT_annotation_BGI_V1.32/MT_annotation_BGI.pl:13-15) (mitoz/annotate/script/MT_annotation_BGI_V1.32/MT_annotation_BGI.pl:28-29)
- The wiki confirms the symptom: MitoZ fails on some PCGs, "e.g. ATP8 is very divergent for some clades", and the remedy offered is to add closer relatives to the protein database [documentation] (https://github.com/linzhi2013/MitoZ/wiki/New-Features)
- Expected E-value of a short query [inference, Karlin-Altschul arithmetic, not run]: with a ~50-aa ATP8 query (Annelida length list: ATP8 148 bp) and a 15-kb genome (about 30,000 six-frame aa), E <= 1e-5 needs a normalised score of about log2(50 x 30,000 / 1e-5) = 37 bits, which a 30-40 % identical 50-aa alignment may not reach; the same 37 bits are easy for a 500-aa gene, so the single global threshold penalises exactly the short genes (mitoz/profiles/CDS_HMM/Annelida-segmented-worms_CDS_length_list:2)
- Reference depth is not the problem for annelids: the shipped Annelida set has 75 ATP8, 74 ATP6, 75 ND4L, 68 ND6 and 74 COX1 proteins (Mollusca 280 ATP8 vs 336 ATP6; Nematoda 13 vs 152, nematodes lack atp8) [our run] (mitoz/profiles/MT_database/Annelida-segmented-worms_CDS_protein.fa:1)
- GeneWise then aligns the best hit region +-2,000 nt with a fixed invertebrate codon table and `-genesf -gff -sum`; a short divergent protein gives a short, possibly truncated model, and everything after is a local fix-up of at most 9 codons (stop) or ref_start + 10 codons (start) [code] (mitoz/annotate/script/MT_annotation_BGI_V1.32/MT_annotation_BGI.pl:426-465) (mitoz/annotate/script/revise_CDS_pos_v6.py:113-137) (mitoz/annotate/script/revise_CDS_pos_v6.py:213-221)
- MitoZ is not systematically bad on atp8: of 31 earlier real MitoZ outputs (scale worms, Annelida clade) 24 NCBI records have CDS and 22 could be mapped to the MitoZ coordinates; MitoZ found 22 of 22 NCBI atp8 and 22 of 22 atp6 (and cox3) with both ends identical, whereas 3' ends of nad2 (6/22), nad5 (6/22), cox1 (12/22), nad6 (12/22) and 5' ends of nad5 (14/22), nad4 (15/22), nad4l (16/22) disagree most; atp8 failure is therefore clade- and divergence-dependent, and the NCBI annotations are not independent of MitoZ/MITOS-type workflows (independence 未确证) (knowledge/experiments/mitos2_pcg/mitoz_scaleworm_vs_ncbi.tsv:1)

### 2.2 Boundary revision in `revise_CDS_pos_v6.py` (already documented, key points for overlaps)
- Stop: first in-frame complete stop 1..9 codons after the GeneWise end (only the last codon of each window is tested); only if none, at each codon step 0..9 `TA` is tried before `T` and the first step that matches is accepted, with the note "TAA stop codon is completed by the addition of 3' Aresidues to the mRNA" is added [code] (mitoz/annotate/script/revise_CDS_pos_v6.py:113-137) (mitoz/annotate/script/revise_CDS_pos_v6.py:148-194)
- The T/TA fallback is almost always satisfiable: a T occurs at a random codon-step with probability about 0.25, so one of 10 steps matches with probability about 0.94 (uniform base composition assumed, more in AT-rich mtDNA) [inference]; the fallback therefore rarely ends with a partial `>` stop, but its T position is not tied to the next tRNA (mitoz/annotate/script/revise_CDS_pos_v6.py:157-163)
- Start: from the GeneWise start upstream 0..(ref_start + 10) codons, the first window whose translation starts with M (Biopython `cds=True`, so table start codons count) and has no internal stop is taken, i.e. the nearest valid start, never the longest ORF; then up to 10 codons downstream; else `<` partial with note [code] (mitoz/annotate/script/revise_CDS_pos_v6.py:217-259) (mitoz/annotate/script/revise_CDS_pos_v6.py:262-308)
- The start check translates only the first 7 codons after the GeneWise start (window `start - 3j` to `GeneWise start + 21` plus TAG), and no step looks at the neighbouring gene, tRNA, or an overlap with the previous PCG [code] (mitoz/annotate/script/revise_CDS_pos_v6.py:221-248)
- Overlapping pairs are not modelled, they are neither required nor forbidden: in the 16 scale-worm genomes where the NCBI record has the 7-nt nad4l/nad4 overlap MitoZ reproduces it in 12 and gives 13-19 nt (nad4 start 6-12 nt upstream of the NCBI start) or a gap of -17 (nad4 start 24 nt inside) in 4 [our run] (knowledge/experiments/mitos2_pcg/mitoz_nad4l_nad4_junction.tsv:1)
- The greedy stop extension into the next gene (COX2 into trnK, ~800 fish genomes) is a maintainer-acknowledged open issue; our curation step P3 exists for it (https://github.com/linzhi2013/MitoZ/issues/175) (README.md:654-656)

## 3. Other annotators and methods

### 3.1 MFannot (Lang lab)
- ORF-first design: `flip -m -l 40 -g <code>` finds ORFs of >= 40 aa (first codon M if a start codon of the code), BLASTP of the ORFs against the protein library, Exonerate for gene models with introns; ORF ends are the first in-frame stop of the code, so every CDS ends in a complete stop and no T/TA incomplete stop is modelled (grep of the script for "incomplete stop", "polyA" and "truncated stop" finds nothing; behaviour on T/TA genomes not tested, 未确证) (Mfannot/mfannot:989-991)
- Start choice is a homolog vote (`AdjustStartByHMM`): the ORF is extended 5' up to the previous stop ("full5"), aligned with the library homologs (named a, b, c, ... in order of BLAST similarity), every position of full5 whose amino acid is an accepted start amino acid (M plus alternative-start amino acids of the code) is a candidate, each of the four closest homologs votes for the candidate nearest to its own start; a candidate wins with >= 3 votes if >= 4 homologs exist, >= 2 votes for 2-3 homologs, >= 1 for a single homolog; otherwise the candidate nearest the median homolog start; candidates more than 2 aa beyond the furthest homolog start are dropped [code] (Mfannot/mfannot:1718-1860) (Mfannot/mfannot:2228-2377)
- If the best start lies far beyond all homolog starts, a "similar start" note is added and the alternative first-M position is stored; if no start exists the start is defined by similarity and flagged "Def by similarity no start found" [code] (Mfannot/mfannot:1790-1860)
- Genes found only by HMM (poorly conserved): start = the last start-codon candidate at or upstream of the alignment start (else the first candidate after it), end = ORF stop + 3, with a comment in the Masterfile when no start codon exists [code] (Mfannot/mfannot:7893-7958) (Mfannot/mfannot:8094-8113)
- Overlap handling is one global parameter, `overlapcut = 30` nt, not gene-specific [code] (Mfannot/.mfannotrc:8)
- Paper (Lang et al. 2023): says MITOS2 "cannot model introns", that BLAST-like search (all tools except MITOS2 and MFannot) has "insufficient sensitivity and precision" and that profile HMMs (hmmsearch, cmsearch) are the better approach; the paper contains no atp8 or overlap rule (text searched for "atp8" and "overlap"); note that the installed MITOS2 with refseq89m uses BLASTX for proteins, the HMM route being `--alarab` (doi:10.3389/fpls.2023.1222186) (mitos/scripts/runmitos.py:1346-1349)

### 3.2 GeSeq (Tillich 2017)
- Boundaries are the BLAT/BLATx hit coordinates themselves (no start/stop search); the GenBank translation is only created if the CDS length is a multiple of 3, starts with ATG/GTG/ACG/TTG and ends with TAG/TGA/TAA/CAG/CGA/CAA (the C-containing triplets allow plant C-to-U editing) [paper] (doi:10.1093/nar/gkx391)
- Evidence tracks are kept side by side instead of merged: best-scoring hit per gene plus the second-best non-overlapping hit as "fragment", optional nhmmer profile-HMM hits as separate `misc_feature`s (profiles built for a manually curated chloroplast set), tRNAs from two de novo predictors; the user compares them [paper] (doi:10.1093/nar/gkx391)
- Metazoan mitochondria are possible only with an appropriate reference set, and the authors did not test outside plants; in a Culicoides benchmark GeSeq missed the rRNAs, overcounted tRNAs or "imprecisely annotated the beginning and the end of their coding region", while MITOS2 and MitoZ recovered all 13 PCGs in both reference genomes [paper] (doi:10.1093/nar/gkx391) (doi:10.1186/s12864-022-08743-x)

### 3.3 MitoAnnotator / MitoFish (Iwasaki 2013; Zhu 2023)
- Rule-based, tuned on fish. Stop: extend the BLASTX hit end by 3 nt until TAA, TAG, AGA or AGG; if none occurs before the next element, atp8, cox1, nad4l, nad5, nad6 may overlap the next element, the other eight PCGs only if the next element is on the other strand, otherwise the gene ends at (next start - 1), which yields incomplete T/TA stops [paper] [inference] (doi:10.1093/molbev/mst141)
- Start: the ATG or GTG that is farthest from the stop and does not overlap the preceding element, with exceptions fitted on an in-house dataset: 1-base overlap allowed for nad1, nad2, nad3, nad5; up to 20 bases for atp6 and nad4; special starts CTG (atp6), TTG (nad1), ATA/ATT (nad3), TTG (cox2) [paper] (doi:10.1093/molbev/mst141)
- Further start rules: of contiguous start codons (e.g. ATGGTGATG) take the last ATG; else the farthest TTG/ATA/ATT/CTG/TTA/ATC/ACG within +30 bp of the preceding element's end; else the first in-frame position after the preceding element [paper] (doi:10.1093/molbev/mst141)
- Length caps (the only gene-specific length rule found in any tool): genes longer than 220 bp (atp8), 750 (cox2), 800 (cox3), 1000 (nad1), 355 (nad3), 535 (nad6) take the furthest start inside the window 170-220 bp (atp8), 650-750, 700-800, 900-1000, 305-355, 435-535; failing that, the start that makes the length closest to the threshold [paper] (doi:10.1093/molbev/mst141)
- Accuracy reported: all 42 newly sequenced fish mitogenomes and 10 atypical ones annotated correctly at single-nucleotide level; for the 42 genomes the 2013 MITOS differed from the experts in the start positions of PCGs in 42 genomes and in the stop positions in 42 genomes (Table 2 counts genomes), which the authors attribute to MITOS requiring PCG lengths to be multiples of three (e.g. CTT as cob stop), and MITOS added a spurious second PCG copy in the D-loop in 3 genomes, one of them a 105-bp ATP8 [paper] (doi:10.1093/molbev/mst141)
- 2023 update (Zhu et al.): tRNA search switched from MiTFi (~160 s) to tRNAscan-SE v2.0 (5 s), BLASTX updated to 2.9.0+; on 3 of 10 atypical genomes start positions became consistent with RefSeq; the PCG boundary algorithm is not described again [paper] (doi:10.1093/molbev/msad035)

### 3.4 MitoFinder, MitoHiFi, MitoFlex
- MitoFinder: BLAST hit, then a codon walk of up to `--nwalk` 5 codons in both directions to the nearest start codon (5') and complete stop codon (3') of the chosen NCBI table; no T/TA handling, no overlap logic (see tools/mitofinder.md); its paper reports that missed genes in 296 ant libraries were mostly "the short and divergent ATP8" (131/296) and the rRNAs [code] [paper] (MitoFinder/genbankOutput.py:147-300) (doi:10.1111/1755-0998.13160)
- MitoHiFi has no boundary logic of its own: it calls MitoFinder (default) or MITOS, rotates the genome to the trnF start, and advises manual checking of annotations before submission [paper] (doi:10.1186/s12859-023-05385-y)
- MitoFlex (Li et al. 2021) is a MitoZ derivative: tblastn 1e-5 (line 81), identity 30 and score 25 filters, GeneWise on the hit +-30 nt; `reloc_genes` translates the GeneWise region +-29/30 nt, takes the first `*` as stop, otherwise the first `TA` then `T` found anywhere in the last 30 nt (not codon-aligned), and the start from an M in the translated region; it keeps MitoZ's single global thresholds and uses a 30-nt window (about 10 codons, as in MitoZ's 9) that is not codon-aligned [code] (https://github.com/Prunoideae/MitoFlex/blob/master/annotation/annotation_tookit.py#L81) (https://github.com/Prunoideae/MitoFlex/blob/master/annotation/annotation_tookit.py#L146-L160) (https://github.com/Prunoideae/MitoFlex/blob/master/annotation/annotation_tookit.py#L317-L361)

### 3.5 Newer and alternative methods (2016-2026)
- Phylogeny-aware HMMs (Al Arab et al. 2017): taxon-specific multiple alignments of annotated PCGs, "enhanced" by fixing unannotated frameshifts, purging wrong sequences and trimming non-conserved end columns, one HMM per taxon; MITOS2 uses such HMMs for the approximate gene positions (paper) and exposes them as `--alarab`, but the refseq89m release lacks them [paper] [code] (doi:10.1016/j.ympev.2016.09.024) (mitos/scripts/runmitos.py:1346-1349)
- DeGeCI (Fiedler et al. 2023): de Bruijn graph of RefSeq mitogenomes plus clustering; when deciding whether a position encodes a gene it considers the two best-scoring genes, because "two genes may well overlap, but the precise gene boundaries may vary slightly among different genomes", has no codon-level boundary correction, and its protein boundaries are slightly less exact than MITOS2's; the authors attribute the difference to MITOS2's start/stop search [paper] (doi:10.3389/fgene.2023.1250907)
- DeGeCI 1.1 (2024) adds the old MITOS1 correction (+-6 nt window, restricted by neighbouring stop/start codons) when a genetic code is given: fraction of predictions starting with a start codon 0.08 -> 0.93 and ending with a stop codon 0.14 -> 0.93; this checks codon validity, not agreement with RefSeq [paper] (doi:10.1093/bioadv/vbae072)
- Literature/web search on 2026-10-20 (Europe PMC, web search) found no 2022-2026 animal-mitogenome method that predicts start/stop boundaries by a new algorithm, deep-learning or protein-language-model approach; MITOS2's probabilistic model remains the most developed; absence of such a tool is a negative search result, not proof (未确证)
- Plant-specific PMGA (2025) treats RNA-editing-created start/stop codons as "start-gain/stop-gain"; not relevant to metazoan mtDNA, where the analogous mechanism is polyadenylation completing T/TA stops (doi:10.1016/j.xplc.2024.101191)
- Aln2tbl (2021) builds an NCBI feature table from a manually refined alignment and writes non-canonical starts and truncated stops as translation exceptions; it advises T rather than TA for truncated stops because TA is not recognised by some downstream programs (tbl2asn) [paper] (doi:10.1080/23802359.2021.1966334)

## 4. Rules from the literature for start, stop, overlap and short genes

### 4.1 Start codon choice in metazoan mtDNA
- Biology (human): 8 of 13 mt-mRNAs begin with the start codon at the very 5' terminal nucleotide, 3 begin less than 4 nt from the 5' end, and the two downstream ORFs of the bicistronic transcripts (ATP6, ND4) lie inside the mature RNA; AUG is used 9 times, AUA and AUU also (ND5 AUA, ND2 AUU, ND1 AUA, ND3 AUA); mt-mRNAs are generally viewed as released by excision of the flanking tRNAs and lacking 5' UTRs, although only ND2 and ND3 fit this completely [paper] (doi:10.1016/j.bbabio.2010.02.036)
- Consequence [inference, generalisation to invertebrates 未确证]: the start codon is expected at or within a few nt of the end of the upstream tRNA/gene, which is the rationale of "take the first eligible start after the preceding gene" (doi:10.1016/j.bbabio.2010.02.036)
- Fourdrilis et al. 2018 (gastropod mitogenomes; corrected 41 of 70 GenBank records) criterion 1: PCGs begin at the first eligible in-frame start codon at the 5' end, i.e. the start codon nearest to the preceding gene without overlapping it, checked for location and gene length by aligning the derived protein with close relatives [paper] (doi:10.1038/s41598-018-36428-7)
- MitoAnnotator reaches nearly the same rule from the other side: the ATG/GTG farthest from the stop that does not overlap the preceding element, with fallbacks ordered TTG/ATA/ATT/CTG/TTA/ATC/ACG within +30 bp; both rules select the most upstream non-overlapping start codon [paper] [inference on equivalence] (doi:10.1093/molbev/mst141)
- Fourdrilis et al. also state the weakness of the conservative rule: choosing the most frequent start and the most consistent length among relatives can miss genuine short/long genes, particularly in variable atp and nad genes, and errors in the reference mitogenome propagate; they corrected "several start codon positions in nad genes which have very variable 5' ends" [paper] (doi:10.1038/s41598-018-36428-7)
- Alternative starts are real: RefSeq annotates ATN (code 5, 13), GTG, TTG (also in code 9 where the table lists only ATG/GTG), and unusual starts concentrate in cox1; MITOS2 therefore learns start frequencies per gene and code and discards starts below 0.01 (details in topics/genetic_codes_start_stop.md) [paper] (doi:10.1093/nar/gkz833)
- Start of atp8: in flatworm and other lophotrochozoan atp8 the first four amino acids are conserved (MPQL; MPQM in most polyclads, MYQM in Stenostomum) while the rest is poorly conserved [paper]; in 44 RefSeq atp8 proteins we checked (40 annelids, human, Drosophila, Apis, sea urchin; 50-68 aa) all begin M-P-[QH]-[LM] (MPHL 33, MPQL 9, MPQM 2), a motif check for the start choice of this gene [our run] (doi:10.1186/s12864-017-3807-2) (knowledge/experiments/mitos2_pcg/atp8_nterm.tsv:1)
- Boore et al. 2005 (Methods Enzymol 395:311-348, doi:10.1016/S0076-6879(05)95019-2) and Cameron 2014 (Syst Entomol 39:400-411, doi:10.1111/syen.12071) are the annotation recommendations that Fourdrilis followed (naming after Boore 2006, doi:10.1089/omi.2006.10.119); their full texts could not be retrieved, so their own rules for start codons, T/TA stops and overlaps are 未确证 here (doi:10.1038/s41598-018-36428-7)

### 4.2 Stop codons and T/TA
- Fourdrilis criterion 3: PCGs end at the first in-frame complete stop codon, or at an abbreviated stop (TA- or T-- in invertebrates) ending immediately before the downstream tRNA, to reduce overlap and keep gene length consistent among relatives; the abbreviated stop arises from cleavage at tRNA ends and polyadenylation [paper] (doi:10.1038/s41598-018-36428-7)
- Human mt-mRNAs need 0, 1 or 2 added A residues to complete the stop (ND5, COX1, COX2, ND4L, ATP8, ND6 none; ATP6, ND1 one; ND2, ND3, ND4, CYTB, COX3 two), poly(A) tails are 37-48 nt in HepG2 cells; the tRNA-punctuation model is the basis of the rule above [paper] (doi:10.1016/j.bbabio.2010.02.036) (doi:10.1038/290470a0)
- RefSeq prefers incomplete stops to small overlaps and annotates T more often than TA; the MITOS2 authors recommend that gene features exclude the polyadenylated positions while CDS features include them [paper] (doi:10.1093/nar/gkz833)
- The 2013 MITOS enforced multiples of three and produced stops such as CTT for cob; MitoAnnotator's "end = next start - 1" rule is what produces its incomplete stops [paper] [inference] (doi:10.1093/molbev/mst141)
- NCBI side: a T/TA CDS needs `transl_except` (T alone preferred over TA by Aln2tbl because TA is not recognised by some tools) and the A-addition note, otherwise table2asn reports NoStop (knowledge/tools/table2asn.md:27-29) (doi:10.1080/23802359.2021.1966334)

### 4.3 Overlapping genes (atp8/atp6, nad4l/nad4)
- Biology: ATP8/ATP6 and ND4L/ND4 are transcribed as bicistronic RNAs with overlapping ORFs; the 5' UTR of the downstream ORF is the out-of-frame end of the upstream ORF and the downstream ORF forms the 3' UTR of the upstream one [paper] (doi:10.1016/j.bbabio.2010.02.036)
- Fourdrilis criterion 2: overlap of two same-strand PCGs in the same reading frame is physically impossible, but is possible if the frames differ [paper] (doi:10.1038/s41598-018-36428-7)
- Observed in six genomes: every overlap of these two pairs on the + strand (6 of 6; the only other overlap, a 1-nt A shared by Drosophila minus-strand nad4/nad4l, has no such shape) has the downstream gene starting at the first base of the overlap with ATG, the upstream gene ending at its last base with TAA or TAG, and a frame offset of 2 nt: Platynereis nad4l/nad4 7 nt ATGTTAA; human atp8/atp6 46 nt (ATG...TAG) and nad4l/nad4 7 nt ATGCTAA; Drosophila atp8/atp6 7 nt ATGATAA; Apis atp8/atp6 19 nt; sea urchin atp8/atp6 10 nt ATGACTATAA [our run] (knowledge/experiments/mitos2_pcg/overlap_junctions_6test.tsv:1)
- Observed in 40 annelid RefSeq genomes (first 40 by accession of the Annelida dedup set): the nad4l/nad4 junction is a 7-nt overlap in 35 genomes (ATGTTAA 21, ATGCTAA 13, ATGATAA 1), a 4-nt ATAA overlap in 1 and absent in 4; atp8 and atp6 do not overlap in any of the 39 scored genomes (1 origin-wrapping record skipped; atp8 is annotated in all 40) [our run] (knowledge/experiments/mitos2_pcg/overlap_junctions_annelid40.tsv:1)
- Annotator conventions: MitoAnnotator lets atp8, cox1, nad4l, nad5, nad6 overlap the following element when no stop is found, allows atp6 and nad4 starts to overlap the preceding element by up to 20 bases, and nad1/2/3/5 by one; MITOS2 allows any overlap up to 50 nt (46 nt human atp8/atp6 is the paper's example); MFannot has a single overlapcut of 30 nt [paper] [code] (doi:10.1093/molbev/mst141) (mitos/scripts/runmitos.py:1156-1162) (Mfannot/.mfannotrc:8)
- Caveat: the overlap length is clade-specific (46 nt human, 19 nt Apis, 7 nt Drosophila, none in annelid atp8/atp6), so a fixed length is wrong while the shape (ATG at the overlap start, stop at its end, frame offset 2) was constant in our data (knowledge/experiments/mitos2_pcg/overlap_junctions_6test.tsv:1)

### 4.4 Short and divergent genes (atp8, nad6)
- atp8 is the shortest PCG (RefSeq lengths in our six genomes 159-207 nt; Annelida length list 148 bp) and has little conserved sequence beyond the N-terminus; it is absent from nematodes, chaetognaths, rotifers and some bivalves, and has been overlooked in flatworms through observation bias ("no atp8 in flatworms") [paper] (doi:10.1186/s12864-017-3807-2) (knowledge/experiments/mitos2_pcg/results.tsv:1)
- Detection evidence that worked for the flatworm atp8 when MITOS failed: manual ORF search in the expected position, N-terminal transmembrane segment (SMART), hydrophobicity profile (positive N-terminus, mostly negative C-terminus), Pfam ATP-synt_8 E-values 0.0073-0.72, RNA-seq reads; BLASTP E-values were only 0.027-0.22 [paper] (doi:10.1186/s12864-017-3807-2)
- Extreme end of the scale: the putative planarian atp8 is so derived that it was labelled with a question mark by the original authors [paper] (doi:10.1186/s12864-017-3807-2)
- MitoAnnotator's explicit length caps cover atp8 (> 220 bp) and nad6 (> 535 bp) besides cox2, cox3, nad1 and nad3, and the transcript end of human ND6 has no consensus [paper] (doi:10.1093/molbev/mst141) (doi:10.1016/j.bbabio.2010.02.036)

## 5. Ideas to integrate

Order = our suggested priority. Each idea gives the rule, the evidence behind it with its label, and a test we can run on the benchmark sets (`benchmark/sets/mito_bench_2026-10.tsv`, the 40 annelid RefSeq genomes, the 31 MitoZ scale-worm outputs). None is implemented yet; "tested" below means the premise was measured, not the rule itself.

- I1 (high) [evidence: code + our run + literature; premise measured, rule untested] tRNA-bounded stop with scored T/TA candidates: for every CDS build three stop candidates, (a) the first in-frame complete stop after the alignment end (<= 9 codons as in MitoZ), (b) TA and (c) T, valid only if those in-frame bases lie directly before the next tRNA/rRNA/CDS; accept (a) only if it overlaps the next feature by <= 2 nt, else take (c)/(b) with `transl_except` and the polyA note; use MITOS2's learned stop frequencies per gene (TAA 0.80-0.86 for atp8/atp6/nad4l/nad6, TNN penalty 1/12, TAN 1/3) only to rank when two candidates are both inside the free space. Evidence: MitoZ extends complete stops up to 27 nt into the next gene (open issue 175); MITOS2 ends later than RefSeq in 15 of 20 incomplete-stop loci, 12 of them at a complete stop; Fourdrilis criterion 3; our P3 curation already does this after the fact and lifted 3' identity from 211 to 254 of 284 PCGs (README.md:673). Test: 3' identical fraction, CDS-tRNA overlap > 2 nt and table2asn NoStop on the scale-worm set, with and without the rule inside candidate selection (https://github.com/linzhi2013/MitoZ/issues/175) (knowledge/experiments/mitos2_pcg/results.tsv:1) (doi:10.1038/s41598-018-36428-7) (README.md:654-656)
- I2 (high) [evidence: our run on 46+22 genomes + literature; rule untested] overlap-junction rule for atp8/atp6 and nad4l/nad4: when both genes of a pair are on the same strand and the alignments end/start within 60 nt of each other, enumerate (down-ATG, up-stop) combinations in which the downstream ATG (or the table's start) is followed, in the frame shifted by 2 nt, by the upstream TAA/TAG within 4-50 nt, and prefer such a junction over a gap or an overlap of any other shape; make the target overlap length a per-class parameter learned from RefSeq of the same class (annelids: 7 nt ATGNTAA; human atp8/atp6 46 nt; Apis 19; Drosophila 7), not a constant. Evidence: 6/6 + strand overlaps of our six genomes and 35/40 annelid nad4l/nad4 junctions have exactly this shape; MitoZ reproduced the 7-nt junction in only 12 of 16 scale-worm genomes where NCBI has it (the other 4 had 13-19 nt or a -17 gap, i.e. a different nad4 or nad4l boundary from the NCBI record); MITOS2 reproduced 5 of the 6 overlaps of our genomes; human data show bicistronic overlapping ORFs. Test: in the 40 annelids and 31 scale-worm outputs, fraction of junctions identical to RefSeq/NCBI before and after the rule; false-positive rate in genomes that have no overlap (annelid atp8/atp6, 39/39 none) (knowledge/experiments/mitos2_pcg/overlap_junctions_annelid40.tsv:1) (knowledge/experiments/mitos2_pcg/mitoz_nad4l_nad4_junction.tsv:1) (doi:10.1016/j.bbabio.2010.02.036)
- I3 (high) [evidence: code + literature + our run; rule untested] targeted rescue of a PCG that MitoZ misses (atp8 first): after MitoZ, list absent genes; for each, run tblastn of only that gene's MITOS2 reference set (`refseq89m/featureProt/<gene>.fas`, 7,641 atp8 proteins) with E <= 1e-2 (MitoZ v1.2's atp8 value, equal to MITOS2's cutoff) in unannotated windows (<= 50 nt overlap with annotated CDS/rRNA); accept a hit only if (i) a complete ORF with a table start and an in-frame stop exists, (ii) its length is inside the learned window with p >= 0.05 (code 5 atp8 126-186 nt; code 2 162-207; code 4 192-255), (iii) for atp8 the translation has an N-terminal hydrophobic/transmembrane segment and starts M-P-[QH]-[LM] (44/44 RefSeq atp8 checked), (iv) at most one copy per gene is kept (the `--best` principle). Evidence: MitoZ lowered then restored the atp8 E-value because of false positives, so extra filters are needed; MitoFinder missed atp8 in 131/296 libraries; flatworm atp8 was recovered by ORF + transmembrane + hydrophobicity evidence when BLAST and MITOS failed; MITOS2 found atp8 in 5/5 of our genomes that have it, none in C. elegans, but a spurious second copy in Apis without `--best`. Limit: flatworm atp8 (E 0.027-0.22) would still fail at 1e-2, needing a profile HMM (Pfam ATP-synt_8). Test: remove atp8 from the Annelida/Mollusca MitoZ database (or exclude the close relatives) and measure recovery and false positives over the 40 annelids plus atp8-lacking genomes (nematodes, C. elegans) (mitoz/annotate/script/MT_annotation_BGI_V1.32/MT_annotation_BGI.pl:28-29) (doi:10.1186/s12864-017-3807-2) (doi:10.1111/1755-0998.13160) (knowledge/experiments/mitos2_pcg/results.tsv:1)
- I4 (medium) [evidence: code + paper + our run; rule untested] gene-specific start priors in MitoZ's start revision: replace "first M within ref_start + 10 codons" by a ranked list of all in-frame start codons between the upstream limit (previous in-frame stop or the end of the previous tRNA/gene minus the allowed overlap) and the GeneWise start, score = learned start frequency of the codon for this gene and code (MITOS2 `auxinfo.json`, drop p < 0.01 but flag) x alignment-position factor delta (1 - relative position in the reference protein), and choose the best; use the length p-value lambda only as a veto (< 0.01) or flag, never as a multiplicative factor. Evidence: the MITOS2 model gives 77.5 % start agreement with RefSeq against < 60 % for the window method; our test shows its start errors arise when RefSeq uses a rare start (11 of 26 cases the MITOS2 start has higher learned frequency than RefSeq's) and when the length prior dominates (sea urchin: 7 of 12 genes, lambda 1.15-9.1 times higher for the shorter start, e.g. atp6 9.1 times against a delta advantage of only 1.3 for the RefSeq start); MitoZ's nearest-valid-start rule is documented as pinned by the reference (open issue 31). Test: 5' identical fraction vs RefSeq/NCBI per gene on the annelid and scale-worm sets, separately for atp8, atp6, nad4l, nad4 (https://github.com/linzhi2013/MitoZ/issues/31) (knowledge/experiments/mitos2_pcg/lenpv_competition_NC_001453.1.tsv:1) (doi:10.1093/nar/gkz833)
- I5 (medium) [evidence: our run + code; rule untested] MITOS2 PCG run as a second opinion with a disagreement report (GeSeq-style evidence tracks, no silent merge): run `runmitos --best` (about 5 min per genome; keep `--finovl` 50) after MitoZ and tabulate per PCG the MitoZ-revised and MITOS2 coordinates; identical = accept; 3' differences of the "complete vs incomplete stop" kind go to I1; 5' differences go to I4 and the Fourdrilis check; differences > 30 nt or any gene present in one tool only go to the curation report. Evidence: the two tools fail differently (MITOS2 3' identical 78 %, with incomplete stops extended; MitoZ 3' identical only 12/22 for cox1 and nad6, 6/22 for nad2 and nad5, but 22/22 for atp8, atp6, cox3), GeSeq shows tracks side by side, DeGeCI and MITOS2 are both approximate at gene ends. Test: agreement-set precision (fraction of agreed boundaries equal to RefSeq) and number of loci sent to review (knowledge/experiments/mitos2_pcg/results.tsv:1) (knowledge/experiments/mitos2_pcg/mitoz_scaleworm_vs_ncbi.tsv:1) (doi:10.1093/nar/gkx391)
- I6 (medium) [evidence: code + literature; no measurement] homolog vote for the start (MFannot): take the aligned starts of the 3-4 closest references from MitoZ's tblastn hits (before the SOLAR merge), project them to the genome, and among valid start codons choose the one nearest to the majority (>= 3 of >= 4, >= 2 of 2-3, 1 of 1), median otherwise, never beyond the furthest reference start + 2 codons. Evidence: MFannot source; MitoZ keeps only the best reference's start (`Ref<start>`); Fourdrilis criterion 1 also checks the protein alignment with relatives. Test: as I4; also report votes per gene (Mfannot/mfannot:2228-2377) (mitoz/annotate/script/revise_CDS_pos_v6.py:213-221) (doi:10.1038/s41598-018-36428-7)
- I7 (low, cheap) [evidence: paper + code; no measurement] learned-table QC flags in `mito_curate.py`: report (not change) a start codon with learned frequency < 0.01 for that gene and code, a stop that is not TAA/TAG/T/TA(/AGA/AGG in code 2), a CDS whose length class (mod 3) disagrees with its `transl_except`, a PCG length outside the p >= 0.05 window (MITOS2 `len_pval`, per code and gene), a same-frame same-strand overlap of any size, and a PCG pair overlapping > 50 nt. Evidence: thresholds from the MITOS2 paper (0.01, 0.001), Fourdrilis criterion 2, MitoAnnotator length caps; the length window is a code-level prior and must stay a flag (sea urchin). Test: flags per genome on the 31 scale-worm outputs, manual check of a sample (doi:10.1093/nar/gkz833) (refseq89m/auxinfo.json:1) (doi:10.1038/s41598-018-36428-7)
- Parameters to carry over if MITOS2 protein output is used anywhere: `--best` (removes the spurious second atp8, also the D-loop duplicates that the 2013 MITOS made), `-c` equal to the pipeline code, the default learned statistics (we ran only these; the NCBI-uniform table with each start 0.167 and TAA = TAG = 0.5 was not compared), and `--finovl` left at 50 unless a real PCG overlap > 50 nt is seen (none among the atp8/atp6 and nad4l/nad4 junctions of 46 genomes; maximum 46 nt in human) [our run] (mitos/scripts/runmitos.py:128-133) (mitos/scripts/runmitos.py:1156-1172) (knowledge/experiments/mitos2_pcg/overlap_junctions_6test.tsv:1)
